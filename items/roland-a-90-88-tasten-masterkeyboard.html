Roland Roland A-90 88-Tasten Masterkeyboard

Master Keyboard Year: 1996

Description

MIDI master keyboard with 88 weighted keys, PA-4 hammer action, adjustable velocity sensitivity, and channel aftertouch. 8 zones (4 internal and 4 external) can be assigned to 4 independent MIDI outputs, and 2 footswitches and 2 expression pedals can be connected. A performance memory with 64 slots and sequencer remote control (Song Select, Tempo, Reset, Start/Stop) are available. A voice expansion board can be installed, transforming the A-90 from a pure master keyboard into an RD-Piano or JV-Synthesizer. The A-90EX model was sold with a pre-installed VE-RD1 board.

Features

  • MIDI Master Keyboard
  • 88 weighted keys
  • PA-4 hammer action
  • Adjustable velocity sensitivity
  • Channel aftertouch
  • 8 zones (4 internal, 4 external)
  • 4 independent MIDI outputs
  • Connects 2 footswitches and 2 expression pedals
  • 64 performance memory slots
  • Sequencer remote control (Song Select, Tempo, Reset, Start/Stop)
  • Supports voice expansion boards (e.g., VE-RD1, VE-JV1, VE-GS1)
  • A-90EX variant includes pre-installed VE-RD1 board
