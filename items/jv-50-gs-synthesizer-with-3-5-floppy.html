JV-50 GS Synthesizer with 3.5" Floppy

Digital Synthesizer Year: 1993

Description

The JV-50 is a 28-voice, 16-part multitimbral, GS-compatible digital synthesizer with 61 velocity-sensitive keys and a sequencer for SMF files. The sound generation is based on the Sound Canvas SC-55MKII module. Sounds cannot be fully programmed, only modified relative to the original in some parameters. These modified "Tones" can be saved, as can 8 Performances, which contain the complete settings for all parts. The JV-50 is identical to the JV-35 except for the sequencer and also has a slot for a Voice Expansion Board, which provides an additional 28 voices with either GS sounds or JV sounds.
