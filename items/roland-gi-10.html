Roland GI-10

Guitar FX Year: 1995

Description

The Roland GI-10 is a guitar-to-MIDI interface for guitars with a 13-pin connection and GK pickup (GK-2, GK-3, etc.). It converts signals from the hexaphonic GK pickup into MIDI notes and other associated MIDI playing data. It also features a standard guitar/microphone input, allowing for monophonic conversion of sung or played signals into MIDI data (requiring precise level control and note separation). For GK signal conversion, users can adjust sensitivity for each string and select polyphonic or monophonic MIDI transmission modes. Additional features include adjustable bend range, octave transposition, fingerpicking optimization, and a built-in tuner.

Features

  • Guitar-to-MIDI interface
  • 13-pin connection
  • GK pickup compatibility
  • Monophonic input for guitar/microphone
  • Polyphonic and Monophonic MIDI transmission modes
  • Adjustable string sensitivity
  • Bend range adjustment
  • Octave transposition
  • Fingerpicking optimization
  • Built-in tuner
  • Expression pedal input
  • Two footswitch inputs
  • MIDI In/Thru/Out
