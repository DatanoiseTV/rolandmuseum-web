Roland JUNO-106 Synthesizer with Memory

Analog Synthesizer Year: 1984

Description

The Juno-106 is a 6-voice analog synthesizer with 61 keys. Each voice features an oscillator (DCO), high-pass filter, dynamic low-pass filter, dynamic amplifier, and an envelope generator. The sound generation is fundamentally the same as its predecessor, the Juno-60. However, the Juno-106 has more patch memory than its predecessor (128 compared to 56), organized into 2 groups with 8 banks of 8 sound programs each. Patch groups can also be offloaded to tape and reloaded. The Juno-106 features a MIDI interface and transmits both notes and parameter values via SysEx data, allowing it to send all necessary parameters to a second Juno-106 (or sequencer) when switching sound programs. The Juno-106 was also sold as the Juno-106S or HS-60 with built-in speakers.

Features

  • 6-voice analog synthesizer
  • 61 keys
  • Per voice: Oscillator (DCO), high-pass filter, dynamic low-pass filter, dynamic amplifier, and an envelope generator
  • 128 patch memories (2 groups, 8 banks, 8 sound programs)
  • Patch groups can be offloaded to tape and reloaded
  • MIDI interface
  • Transmits notes and parameter values via SysEx data
  • Also sold as Juno-106S or HS-60 with built-in speakers
  • Dimensions (W x H x D): 992 mm x 120 mm x 320 mm
  • Weight: 10 kg
  • Power consumption: 25W
  • Built-in power supply, Roland power cable
