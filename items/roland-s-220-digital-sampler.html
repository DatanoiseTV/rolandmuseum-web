Roland S-220 Digital Sampler

Sampler Year: 1987

Description

The Roland S-220 Digital Sampler is a 16-voice sampler module in 19-inch format with 2U and a built-in 2.8-inch floppy disk drive (Quick-Disk format, QD). It samples with 12-bit and either 15 or 30kHz, but already has 16-bit A/D converters. The internal memory of 256kB is divided into 4 banks of 64kb each, so that all samples together can be a maximum of 4.4 seconds long, approximately 1.1 seconds per bank. To record a 'long' sample, two banks can be combined. Samples can be edited in the device, provided with a dynamic envelope, and looped; however, there is no dynamic filter. The S-220 reads QuickDisks from S-10 and MKS-100, so it is data-compatible with the L-100 series. The S-220 operates in MIDI mono mode, where up to 8 consecutive channels can be used, or up to 4-fold multitimbral in poly mode, where voice allocation is not dynamic but must be preselected. In poly mode, the note range per channel can be limited. Monitor and mouse operation like in the 'big brothers' S-50, S-330 is not provided; here, the operating elements of the S-220 and the two-line display must suffice.

Features

  • 16-voice sampler
  • 19-inch format (2U)
  • Built-in 2.8-inch floppy disk drive (QuickDisk)
  • 12-bit sampling (15 or 30kHz)
  • 16-bit A/D converters
  • 256kB internal memory (4 banks of 64kB)
  • Sample editing, looping, dynamic envelope
  • No dynamic filter
  • MIDI mono mode (up to 8 channels)
  • 4-fold multitimbral in poly mode
  • Data compatible with L-100 series
