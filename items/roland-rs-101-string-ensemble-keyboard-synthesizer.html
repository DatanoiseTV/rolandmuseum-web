Roland RS-101 String-Ensemble, Keyboard Synthesizer

Analog Synthesizer Year: 1975

Description

The Roland Strings RS-101 is a polyphonic, analog keyboard with 61 non-velocity-sensitive keys designed to produce string emulations. The RS-101 is permanently built into an instrument case with a detachable lid. It features two keyboard zones for which a total of 3 sounds (Brass, two String sounds) can be independently enabled and disabled. The Brass sound and the two String sounds can be separately adjusted in tone, and a fixed-frequency vibrato's intensity can be controlled for the entire keyboard. For each keyboard zone, the volume can be slightly attenuated with a rocker switch, and the attack time can be switched between Slow and Fast. A master volume control is present. There are no further sound shaping settings. There is no headphone output, only two line outputs that carry the same mono signal at higher and lower levels. Unlike other string ensembles of its time, the RS-101 has independent envelopes for individual voices.

Features

  • Polyphonic analog keyboard
  • 61 non-velocity-sensitive keys
  • Designed for string emulation
  • Built into an instrument case with detachable lid
  • Two keyboard zones
  • 3 sounds (Brass, two String sounds) independently switchable per zone
  • Separate tone control for Brass and String sounds
  • Intensity control for fixed-frequency vibrato
  • Rocker switch for volume dampening and attack time (Slow/Fast) per zone
  • Master volume control
  • Two line outputs (high/low level mono)
  • Independent envelopes for individual voices
