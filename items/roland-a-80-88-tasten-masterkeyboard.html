Roland A-80 88 Tasten Masterkeyboard

Other Year: 1989

Description

The A-80 is a 4-zone master keyboard with 88 weighted keys and polyphonic aftertouch. It features a combined pitch bend/modulation lever, as well as separate pitch bend and modulation wheels, and 4 independent MIDI Outs, along with MIDI Thru and a mergeable MIDI IN. For each zone, the MIDI channel, program change, volume (CC#7), bender on/off, velocity curve, and aftertouch behavior (curve and channel-specific or polyphonic) can be separately stored in a PATCH. Furthermore, for each PATCH and for each individual zone, the assignment of the four sliders and four buttons to controller numbers can be defined differently. There are 4 jacks for connecting either footswitches or control pedals (EV-5), which then assume the function of the corresponding slider or button. 64 patches can be named and stored internally, along with 32 chains. A memory card doubles the storage space. Data can also be sent and received via MIDI SysEx. The A-50 and A-80 were the only Roland keyboards with polyphonic aftertouch.

Features

  • 4-zone master keyboard
  • 88 weighted keys
  • Polyphonic aftertouch
  • Combined pitch bend/modulation lever
  • Separate pitch bend and modulation wheels
  • 4 independent MIDI Outs, MIDI Thru, mergeable MIDI IN
  • Per-zone configurable MIDI channel, program change, volume, bender on/off, velocity curve, and aftertouch behavior (stored in PATCH)
  • Four assignable sliders and four assignable buttons with controller numbers
  • 4 jacks for footswitches or control pedals
  • 64 internal patches, 32 chains (expandable with memory card)
  • MIDI SysEx support
