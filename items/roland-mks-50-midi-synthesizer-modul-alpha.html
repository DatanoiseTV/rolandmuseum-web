Roland MKS-50 MIDI Synthesizer Modul "ALPHA"

Analog Synthesizer Year: 1986

Description

The MKS-50 is a 6-voice, digitally controlled analog synthesizer module in a 1U 19-inch rackmount format. It is compatible with SysEx data from the Alpha Juno-1 and Alpha Juno-2. For convenient parameter editing, the optional PG-300 programmer can be connected via MIDI. Each voice features a DCO, fixed high-pass filter, dynamic low-pass filter, dynamic amplifier, one envelope generator, and one LFO. Sounds can be further enhanced with a built-in chorus effect. It offers 64 immutable presets and 64 savable user sounds, though adjustable parameter values are somewhat coarsely stepped.

Features

  • 6-voice digitally controlled analog synthesizer module
  • 1U 19-inch rackmount format
  • SysEx data compatible with Alpha Juno-1 and 2
  • Supports optional PG-300 programmer via MIDI
  • Per voice: DCO, fixed high-pass filter, dynamic low-pass filter, dynamic amplifier, 1 envelope generator, 1 LFO
  • Built-in chorus effect
  • 64 immutable presets
  • 64 savable user sounds
  • Coarsely stepped parameter values
  • Dimensions: 482(W) x 44(H) x 290(D) mm
  • Weight: 3.5 kg
