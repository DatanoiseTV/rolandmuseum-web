Roland JU-2

Analog Synthesizer Year: 1985

Description

The Alpha Juno-2 (JU-2) is a 6-voice, digitally-controlled analog synthesizer with 61 velocity-sensitive keys. It's compatible with SysEx data from the Alpha Juno-1, HS-10, HS-80, and MKS-50. The PG-300 programmer can be connected via MIDI for easier parameter editing. Each voice has a DCO, fixed high-pass filter, dynamic low-pass filter, dynamic amplifier, one envelope generator, and one LFO. A chorus effect can enhance the sounds. It has 64 factory presets and 64 user-programmable sounds.
