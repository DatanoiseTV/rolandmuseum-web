Roland GR-500

Guitar/Bass FX Year: 1977

Description

The Roland GR-500 is a polyphonic, analog guitar synthesizer with a 24-pin connection. It could only be controlled with the special GS-500 guitar. It features five sections: Guitar input, Polyensemble, Bass, Solo synthesizer, and a control section for external synths. The GR-500 was one of the first guitar synthesizers.

Features

  • Polyphonic
  • Analog
  • 24-pin connection
  • Requires GS-500 guitar
  • Five sections (Guitar, Polyensemble, Bass, Solo, Control)
  • Three output buses (CH1-CH3, MIX)
  • CV/Gate outputs
