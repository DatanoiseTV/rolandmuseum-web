Roland TR-33

Drum Machine / Rhythm Year: 1972

Description

The TR-33 Rhythm Composer, also known as the Rhythm 33, is an analog rhythm machine with 8 rhythms selectable via buttons and 12 more selectable via a rotary switch. These rhythm groups can be combined, but fills are not available. It's the smallest rhythm machine in Roland's first series, which also includes the TR-77 and TR-55. The design allows mounting under an organ keyboard. Its only output is a mono signal on the underside. Tempo is set via a rotary control; synchronization is not possible.

Features

  • 8 button-selectable rhythms
  • 12 rotary-switch-selectable rhythms
  • Combination of rhythm groups
  • No fills
  • Mono output
  • Rotary tempo control
  • No synchronization
  • Analog
