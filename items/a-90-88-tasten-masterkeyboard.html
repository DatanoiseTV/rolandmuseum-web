A-90 88-Tasten Masterkeyboard

Pianos Year: 1996

Description

The Roland A-90 is a versatile MIDI master keyboard with 88 weighted keys, PA-4 hammer action, adjustable velocity sensitivity, and channel aftertouch. It features 8 zones (4 internal and 4 external) assignable to 4 independent MIDI outputs, along with connections for footswitches and expression pedals. It includes performance memory and sequencer remote control, and can be expanded with voice boards to function as an RD-Piano or JV-Synthesizer.

Features

  • 88 weighted keys
  • PA-4 hammer action
  • Adjustable velocity sensitivity and channel aftertouch
  • 8 zones (4 internal, 4 external)
  • Assignable to 4 independent MIDI outputs
  • Connections for 2 footswitches and 2 expression pedals
  • 64-slot performance memory
  • Sequencer remote control (Song Select, Tempo, Reset, Start/Stop)
  • Ability to install a voice expansion board, transforming it into an RD-Piano or JV-Synthesizer
  • Also sold as A-90EX with pre-installed VE-RD1 board
  • Dimensions: 1456(W) x 143(H) x 405(D) mm
  • Weight: 23.7 kg
  • Integrated power supply, Roland power cable
  • Included accessory: DP-6 Footswitch (Sustain Pedal)
  • Recommended accessories: DP-2 Footswitch (Sustain Pedal), M-512E RAM memory card, VE-RD1 Voice Expansion Board, VE-JV1 Voice Expansion Board, VE-GS1 Voice Expansion Board, PJ-1M Audio Cable, PCS Audio Cable, EV-5 Expression Pedal, MSC MIDI Cable, RH Headphones
