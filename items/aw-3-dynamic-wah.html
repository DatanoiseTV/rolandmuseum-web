Boss AW-3 Dynamic Wah

Guitar Effect Pedal Year: 1996

Description

The BOSS AW-3 Dynamic Wah uses a digital processor instead of an analog circuit, offering a variety of classic and modern wah sounds, including Touch-Wah, Auto-Wah, and "Humanizer." An expression pedal can be connected for traditional pedal-wah effects, and a dedicated bass input is available for bassists. Key Features: * Five different Wah Modes * Touch Wah with Up or Down filter sweeps * Envelope processing for accurate dynamics response * Auto-Wah with tap tempo or external expression pedal control * Humanizer effect with five vowel sounds and expression pedal morphing * Classic pedal-wah via external expression pedal * Dedicated bass input
