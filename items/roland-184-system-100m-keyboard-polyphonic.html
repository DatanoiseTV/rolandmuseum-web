Roland 184 System-100M Keyboard, polyphonic

Eurorack / Modular Year: 1982

Description

The 4 CV COMPUPHONIC KEYBOARD CONTROLLER 184 for the System-100M is a polyphonic control keyboard with 49 keys for four independent voices and has four outputs each for CV and GATE. A special feature is a built-in AUTO-ARPEGGIO (arpeggiator) that can also be triggered by external rhythm devices.

Features

  • Polyphonic control keyboard
  • 49 keys
  • 4 independent voices
  • 4 CV outputs
  • 4 GATE outputs
  • Built-in auto-arpeggiator
  • Arpeggiator can be triggered by external rhythm devices
