Roland M-SE1

Sound Expansion Synthesizer Module Year: 1995

Description

The M-SE1 is an 8-part multitimbral sound module specifically designed for string ensembles and solo strings. It is based on the sound generation of the JV-80 but contains only specialized string waveforms. With the M-SE1, special string-typical effects can be triggered through legato playing, which are not possible with other JV synthesizers. Therefore, the sounds of the M-SE1 are not available as an expansion board. The M-SE1 can be operated in either Patch mode or Performance mode. In Patch mode, only one part is active; in Performance mode, all eight are active, with the eighth part intended for a rhythm set. The MIDI channel can be set for each part. The M-SE1 has no user patches but can be modified via SysEx data. A patch consists of up to four Tones, each with a dynamic filter and amp, two LFOs, and three envelopes, with two Tones linked via 10 possible Structures.
