Roland PR-1G

Sequencer Year: 1992

Description

The PR-1G is a simple 2-track MIDI sequencer without editing functions but with a built-in library of piano pieces for practice. The PR-1G differs from the PR-1 only in its selection of built-in pieces; the G version (G for German) contains German titles.

Features

  • 2-track MIDI sequencer
  • built-in piano piece library
  • approximately 4000 event storage for own recordings
  • 1 song recording capacity
  • no data backup function
  • data retained after power off (if battery is active)
  • metronome with adjustable time signatures and tempo (10-250 BPM)
