Roland 717 A System-700, Sequenzer

Analog Sequencer Year: 1976

Description

The Roland 717A is a module of the System-700 and contains an analog sequencer (step sequencer). It is the largest module of the System-700, occupying an entire block (BLOCK 3). Unlike competing modular sequencers, the 717A can be used immediately without internal patching. The 717A is designed as a three-channel, 12-step sequencer, featuring 36 knobs for setting CV voltage. These 36 controls can be chained in series for a total of 36 steps, or used in parallel mode as three independent rows to control parameters like pitch (Row 1), timbre (Row 2), and volume (Row 3). The set sequence cannot be saved, but as with all analog step sequencers, individual values can be quickly changed with a dedicated knob while the sequence is running. Each row of controls, called a channel, has a three-position switch for setting the control voltage (2 Volts, 4 Volts, and 10 Volts), which is comparable to a foot position selector for pitch control. The duration of each step is settable for all three channels collectively. A multi-position rotary switch offers divisors 1, 1/2, 1/4, 1/8, 1/16, and 1/32 for timing dynamics. Furthermore, there is a control for fine-tuning time values per step for all channels, allowing for 'programming' dotted notes, accelerandi, and rubati (even though nothing is saved). The Step-Selector allows choosing how many of the maximum 16 steps per channel are actually used, to bypass unwanted pauses. One can also limit the use to different channels, e.g., only Channel A, Channel A and B in series, or all three channels in series for the maximum possible 36 steps. The internal clock oscillator controls the speed of a sequence. Alternatively, an external clock signal, such as from a MIDI clock interface, can be used. The pulse-width rotary control in the clock oscillator section sets the gate time per note.

Features

  • Module for Roland System-700
  • Analog step sequencer
  • Largest module of the System-700, occupies Block 3
  • No internal patching required for immediate use
  • Three-channel, 12-step sequencer
  • 36 CV voltage control knobs
  • Controls can be chained in series for 36 steps
  • Parallel mode offers three independent rows for control (e.g., pitch, timbre, volume)
  • Sequences cannot be saved
  • Real-time modification of values during playback
  • Each channel has a three-position switch for control voltage (2V, 4V, 10V)
  • Multi-position rotary switch for common step duration (divisors 1, 1/2, 1/4, 1/8, 1/16, 1/32)
  • Fine-tuning control for time values per step (for dotted notes, accelerandi, rubati)
  • Step-Selector to choose active steps (max 16 per channel)
  • Flexible channel usage (e.g., Channel A only, A+B in series, all three in series for 36 steps)
  • Internal clock oscillator for speed control
  • External clock signal input (e.g., via MIDI clock interface)
  • Pulse-width rotary control in clock oscillator section for gate time per note
  • Integrated power supply, fixed power cable
  • Depth: 300 mm
