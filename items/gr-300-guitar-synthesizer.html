GR-300 Guitar Synthesizer

Analog Synthesizer Year: 1980

Description

The GR-300 is a 6-voice polyphonic analog synthesizer designed for 24-pin guitar control systems. Each string controls one of the six VCOs, which can also be individually switched off via 6 String Select switches if needed. A globally switchable compressor significantly extends sustain. For two integrated footswitches (A and B), a pitch deviation and a common rise and fall time can be set, defining how quickly the deviation is reached or released. Two switches above them determine whether the deviation is applied only while a footswitch is pressed or alternately with each press. For the subsequent filter, the attack time and the sensitivity of the filter envelope to the strike can be adjusted, or switched off with an integrated footswitch if necessary. Another footswitch can invert the envelope. Cutoff frequency and resonance are adjusted with the guitar's controls. The intensity of LFO pitch modulation is also controlled from the guitar, with a rate knob available on the GR-300 itself. Vibrato is activated by pressing the 'Touch-Plate' sensors next to the guitar pickup. DUET is the fifth footswitch, which activates a chorus effect. On the rear, there are connections for a pedal to control the cutoff frequency, buttons for the compressor, sweep trigger, and string select, the 24-pin connector, and audio outputs MIX/SYNTH and GUITAR. If GUITAR output is used, the pure guitar signal is sent there and no longer routed to the shared MIX output. The GR-300 responds very quickly to the controlling guitar and can be controlled by G-202, G-303, G-707, G-808, and a mounted GK-1. The first control guitar, GS-500, is not suitable.

Features

  • 6-voice polyphonic analog synthesizer
  • Designed for 24-pin guitar control systems
  • Each string controls an individual VCO (6 VCOs total)
  • Individual string select switches
  • Switchable compressor for sustain extension
  • Two footswitches (A and B) for pitch deviation with adjustable rise/fall times
  • Filter with adjustable attack time and envelope sensitivity
  • Integrated footswitch for filter cutoff or envelope inversion
  • Guitar-controlled cutoff frequency and resonance
  • Guitar-controlled LFO pitch modulation intensity (GR-300 has LFO rate control)
  • 'Touch-Plate' sensors for vibrato activation
  • 'DUET' footswitch for chorus effect
  • Rear connections for cutoff pedal, compressor, sweep, string select
  • 24-pin input
  • MIX/SYNTH and GUITAR audio outputs (GUITAR output sends pure guitar signal)
  • Fast response to controlling guitar
  • Compatible with G-202, G-303, G-707, G-808, GK-1
  • Integrated power supply
  • Dimensions: 400 x 100 x 290 mm
  • Weight: 5 kg
