Roland Roland MC-300 Micro Composer mit 3,5" Floppy

MIDI Sequencer Year: 1988

Description

The MC-300 is a song-oriented MIDI sequencer featuring two independent MIDI outputs and a 3.5-inch floppy drive, with its operating system requiring loading from a diskette upon startup. Its hardware is largely similar to the MC-500, but it uses small, flat buttons instead of the larger, high-travel buttons. The MC-300 was initially bundled with MRC-300 software, transforming it into a 4-track sequencer capable of recording all 16 MIDI channels on each track. Additionally, a rhythm track is available, allowing for the arrangement of up to 90 rhythm patterns, each with up to 32 distinct note numbers, which can also be user-created. The MC-300 can store a maximum of 8 songs in memory, provided there is sufficient space. The 'Microscop' function enables comprehensive editing of all entries (events). However, a drawback is the frequent need to reinsert the system diskette for various functions. The MC-300 is also compatible with other operating systems designed for the MC-500 and MC-500MKII. With the S-MRC (Super-MRC) software, the MC-300 expands to an 8-track sequencer, also featuring a pattern-oriented rhythm track where up to 240 patterns can be created. The MRP-500 Performance Package facilitates the creation of stage-ready MRC-300 song sequences, which can be initiated with or without pauses and repetitions via a simple button press. The Rhythm Bank MRD-500 provides pre-programmed patterns and software for arranging rhythm tracks, while the Bulk Librarian MRB-500 allows for managing bulk dumps from various devices, including non-Roland equipment. Furthermore, the MRM-500 software was available for converting MRC-500 and S-MRC songs to Standard MIDI Files (SMF) and vice versa. Unlike the MC-500, the MC-300's memory cannot be expanded and has a maximum capacity of 25,000 events. The MC-300 supports synchronization internally or externally via MIDI Clock signals, as well as via an FSK signal (Tape Sync) for tape recorders.

Features

  • Song-oriented MIDI sequencer
  • 2 independent MIDI outputs
  • 3.5-inch floppy drive (for OS and data storage)
  • Operating system loaded from diskette
  • 4-track sequencing (with MRC-300 software)
  • Records all 16 MIDI channels per track
  • Rhythm track with up to 90 user-creatable patterns (expandable to 240 with S-MRC)
  • Stores up to 8 songs in memory
  • 'Microscop' function for full event editing
  • Compatible with MC-500/MC-500MKII operating systems
  • 8-track sequencing (with S-MRC software)
  • MRP-500 Performance Package for live song sequences
  • MRD-500 Rhythm Bank for pre-programmed patterns and arrangement software
  • MRB-500 Bulk Librarian for managing bulk dumps (including non-Roland devices)
  • MRM-500 software for Standard MIDI File (SMF) conversion
  • Maximum 25,000 events memory (non-expandable)
  • Internal or external MIDI Clock synchronization
  • FSK (Tape Sync) for tape recorders
