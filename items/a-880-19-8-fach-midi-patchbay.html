A-880 19" 8-fach MIDI Patchbay

Utility Year: 1988

Description

The Roland A-880 is a 19-inch rack-mountable MIDI patchbay featuring 8 inputs and 8 outputs. It offers 64 memory slots for routing configurations, allowing any input to be routed to multiple outputs. MIDI IN1 can also be merged with another input. The patchbay operates without a display, relying on illuminated buttons for control.

Features

  • 19-inch rack-mountable MIDI patchbay
  • 8 MIDI inputs and 8 MIDI outputs
  • MIDI IN1 can be merged with another input
  • 64 memories for routing assignments
  • Any input can be routed to multiple outputs
  • No display, only illuminated buttons (which complicates programming and overview)
  • Integrated power supply with fixed power cable
  • Dimensions: 482(W) x 88(H) x 286(D) mm
  • Weight: 2 kg
  • Recommended accessory: MSC MIDI cable
