WS-100T Wireless System Sender

Utility Year: 1989

Description

The WS-100T is a transmitter designed for the WS-100 wireless system. It allows guitars or microphones to be connected via a 6.3mm jack, offering wireless transmission across four distinct frequencies. For proper operation, the accompanying WS-100 receiver must be set to the same frequency.

Features

  • Transmitter for WS-100 wireless system
  • Input: 6.3mm jack for guitar or microphone
  • Available in four different frequencies: 169.445MHz, 170.245MHz, 171.105MHz, 171.905MHz
  • Requires WS-100 receiver with matching frequency
  • Dimensions: 51 (W) x 120 (H) x 22 (D) mm
  • Weight: 0.13 kg
  • Power: 1 x 9V block battery (6LR61)
