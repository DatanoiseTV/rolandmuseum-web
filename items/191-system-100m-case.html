Roland 191 System 100M Case

Modular Synthesizer Accessories Year: 1979

Description

The 191 frame for the System-100M accommodates and powers five synthesizer modules. The frame provides basic interconnections between the modules, making CV and gate signals from the keyboard available to all modules without separate patch cables.

Features

  • Houses 5 System 100M modules
  • Provides power to modules
  • Basic interconnections for CV/Gate signals
