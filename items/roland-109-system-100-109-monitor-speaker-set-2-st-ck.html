Roland 109 System 100, 109 Monitor Speaker Set (2 Stück)

Monitor Speakers Year: 1976

Description

The 109 speaker module for the System-100 consists of a pair of speaker cabinets with two 16cm full-range speakers, each at 8 Ohm and a maximum power handling of 3.5W. The dimensions refer to a single speaker cabinet.

Features

  • Pair of monitor speaker cabinets
  • Designed for Roland System-100
  • Two 16cm full-range speakers per cabinet
  • 8 Ohm impedance per speaker
  • Maximum power handling: 3.5W per speaker
  • Passive speakers (no internal power supply needed)
  • Dimensions (per cabinet): 280 x 305 x 155 mm
  • Weight (per cabinet): 5 kg
