Roland A-110 MIDI Signal Indicator

Utility Year: 1987

Description

The A-110 MIDI SIGNAL INDICATOR is an LED display for MIDI note data, arranged like a keyboard. The A-110 displays the full range of 88 keys (A1 to C8). This allows for easy monitoring of MIDI messages such as note on/off, program change, and hold. Requiring only one rack unit, the A-110 is a valuable monitoring tool.

Features

  • MIDI Signal Indicator
  • LED display for MIDI note data
  • Displays the full range of 88 keys (A1 to C8)
  • Enables easy monitoring of MIDI messages like note on/off, program change, and hold
  • Requires only one rack unit (1U)
  • Built-in power supply
