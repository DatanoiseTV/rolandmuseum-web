Roland A-50 76-Tasten Masterkeyboard

Master Keyboard Controller Year: 1988

Description

The A-50 is a 4-zone master keyboard with 76 synthesizer-action keys and polyphonic aftertouch. It features a combined pitch bend/modulation lever, as well as separate pitch bend and modulation wheels, and 4 independent MIDI Outs along with MIDI Thru and a mergeable MIDI In. For each zone, the MIDI channel, program change, volume (CC#7), bender on/off, velocity curve, and aftertouch behavior (curve and channel-specific or polyphonic) can be stored separately in a PATCH. Furthermore, for each PATCH and for each individual zone, the assignment of the four sliders and four buttons to controller numbers can be determined differently. There are 4 jacks for connecting either footswitches or control pedals (EV-5), which then assume the function of the slider or button of the same number. 64 patches can be named and stored internally, as well as 32 chains. A memory card doubles the memory space. Data can also be sent and received via MIDI SysEx. The A-50 and A-80 were the only Roland keyboards with polyphonic aftertouch.

Features

  • 4-zone master keyboard
  • 76 synthesizer-action keys
  • Polyphonic aftertouch
  • Combined pitch bend/modulation lever
  • Separate pitch bend and modulation wheels
  • 4 independent MIDI Outs, MIDI Thru, and mergeable MIDI In
  • Patch storage for MIDI channel, program change, volume, bender, velocity curve, aftertouch behavior per zone
  • Assignable functions for four sliders and four buttons per zone
  • 4 jacks for footswitches or control pedals
  • 64 internal patches, 32 chains
  • Memory card slot to double storage
  • MIDI SysEx data transfer
