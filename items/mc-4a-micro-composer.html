Roland MC-4A Micro-Composer

Sequencer Year: 1981

Description

The MC-4 is a digital sequencer for CV/Gate signals with 4 independent tracks. Sequences can be programmed step-by-step or played in using a CV/Gate keyboard. Two-stage input (first pitch, then step length) is also possible. All entries can be edited on the MC-4, although one must get used to a special display on the 15-character screen. Each track provides two control voltages (CV-1 and CV-2), Gate, and an "MPX" trigger signal for, e.g., portamento, allowing control of not only pitch but also dynamics or the filter of a connected synthesizer. The MC-4 has a built-in DIN-SYNC jack and can serve as a synchronization master or slave for other DIN-SYNC equipped devices, such as CSQ-600, CR-8000, TB-303, MC-202, TR-606, TR-808. Using the TAPE SYNC connections, the MC-4 can also deliver an FSK signal that is recorded on a tape and subsequently allows the MC-4 to run synchronously. Furthermore, the tempo can also be controlled externally via a control voltage. Entered sequences must be saved to tape or a cassette recorder before disconnecting power if one wishes to use them again. Accordingly, functions for saving, loading, and verifying data on external audio recording devices (today, one can also use HD recorders) are available. The MC-4 was delivered as MC-4A with 16kB internal memory for approx. 3700 notes/events or as MC-4B with 48kB for approx. 11500 notes/events and an interface for the data cassette recorder "MTR-100". The MC-4A could later be upgraded to a full MC-4B with the OM-4 retrofit kit.

Features

  • Digital CV/Gate sequencer
  • 4 independent tracks
  • Step-by-step programming
  • Real-time input via CV/Gate keyboard
  • Two-stage input (pitch then step length)
  • Editing capability via 15-character display
  • Per track: CV-1, CV-2, Gate, MPX trigger signal (for dynamics, filter, portamento)
  • Built-in DIN-SYNC (master/slave capability)
  • TAPE SYNC connections for FSK signal (tape storage)
  • External tempo control via CV
  • Data saving, loading, and verification for external audio recording devices
  • MC-4A: 16kB internal memory (approx. 3700 notes/events)
  • MC-4B: 48kB internal memory (approx. 11500 notes/events) and MTR-100 interface
  • MC-4A upgradable to MC-4B with OM-4 retrofit kit
