Roland GR-1 Guitar Synthesizer

Guitar/Bass FX Year: 1980

Description

The Roland GR-1 guitar synthesizer allows guitarists to control a wide range of sounds and MIDI equipment using their guitar. It features Roland's latest synthesizer technology in a compact pedal unit. It includes editing capabilities, effects, and a built-in 4-track sequencer. It is compatible with the GK-2 guitar driver and an optional Wave Expansion Board (SR-GR1-01) for an additional 200 sounds.

Features

  • GK-2 compatible
  • Built-in 4-track sequencer
  • Wave Expansion Board compatible (SR-GR1-01, adds 200 sounds)
  • 64 internal patches
  • Additional 64 patches storable on M-256 E memory card
  • MIDI in/out
  • Foot switches for parameter change and sound selection
