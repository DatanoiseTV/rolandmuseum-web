Roland GR-300

Guitar/Bass FX Year: 1980

Description

The GR-300 is a 6-voice polyphonic analog synthesizer for 24-pin system control guitars. Each string controls one of the six VCOs, which can also be switched off individually via 6 string select switches if required. A jointly switchable compressor significantly extends the sustain. For 2 attached foot switches (A and B), a pitch deviation and a common rise and fall time can be set, the times in which the deviation is reached or left again. Two switches above determine whether the deviation is only executed while a switch is pressed or alternately with each press. For the following filter, the attack time and the sensitivity of the filter envelope to the stroke can be set or switched off if necessary with an integrated foot switch. Another foot switch can invert the envelope. Cutoff frequency and resonance are set using the guitar's controls. The intensity of the LFO pitch modulation, whose speed (rate) is in turn controlled by a control on the GR-300. Vibrato is switched on by pressing the sensors next to the guitar pickup, referred to as "Touch-Plate". DUET is the name of the fifth foot switch, with which a chorus effect is switched on. On the back there are connections for a pedal to control the cutoff frequency, buttons for the compressor, triggering a sweep and string select, the 24-pin connection and the audio outputs MIX/SYNTH and GUITAR. If GUITAR is engaged, the pure guitar signal is output there and is no longer routed to the common MIX output.

Features

  • 6-voice polyphonic
  • Analog synthesizer
  • 24-pin system
  • 6 String Select switches
  • Compressor
  • 2 footswitches (pitch deviation, rise/fall time)
  • Filter attack time
  • Filter envelope sensitivity
  • Foot switch for envelope inversion
  • LFO pitch modulation
  • Touch-Plate vibrato
  • Chorus effect (DUET footswitch)
  • Pedal input for cutoff frequency
  • 24-pin connection
  • MIX/SYNTH and GUITAR audio outputs
