Roland W-30

Sampler Workstation Year: 1989

Description

The W-30 'Music Workstation' is a 16-voice digital sampler with a 61-key velocity-sensitive keyboard, a 3.5-inch floppy drive for sample storage, and a built-in sequencer comparable to the MC-500. The sample memory, which offers 2 x 7.2 seconds at 30kHz or 2 x 14.4 seconds at 15kHz, is not expandable. The 12-bit resolution inherited from the S-50 is compensated by excellent 16-bit converters, resulting in a relatively good sound. The sound basis consists of a maximum of 32 raw samples, which are assigned playback parameters to become 'Tones'. Tones can be freely distributed across the keyboard and saved as 'Patches' (sound programs). The W-30 allows for 16 patches. Like the S-330 and S-550, the W-30 features dynamic filters. The sequencer has a tempo track and 16 MIDI tracks, with each track capable of recording data on all 16 MIDI channels. The W-30 can read song data from Director S sequencers of other S-samplers, MC-500, and Super-MRC. Operation is performed using various buttons and a combination of cursor and value wheels. Visual feedback is provided by an 8-line LCD with waveform display. However, operation is not as comfortable as with other samplers that allow mouse and monitor connections. Data storage uses the built-in 3.5" floppy drive or an external hard drive (SCSI, max 80MB!), provided the KW-30 SCSI interface is installed and a functional hard drive is connected. As with all other S-samplers, the operating system must first be loaded from a data medium after power-on.

Features

  • 16-voice digital sampler
  • 61-key velocity-sensitive keyboard
  • Built-in 3.5-inch floppy drive for sample storage
  • Built-in sequencer (comparable to MC-500)
  • Sample memory: 2 x 7.2 seconds at 30kHz or 2 x 14.4 seconds at 15kHz (not expandable)
  • 12-bit resolution with 16-bit converters for good sound quality
  • Max 32 raw samples
  • Supports up to 16 Patches (sound programs)
  • Dynamic filters (similar to S-330 and S-550)
  • Sequencer with a tempo track and 16 MIDI tracks
  • Each MIDI track can record data on all 16 MIDI channels
  • Can read song data from Director S sequencers (S-samplers, MC-500, Super-MRC)
  • Operation via buttons, cursor wheel, and value wheel
  • 8-line LCD with waveform display
  • Data storage via built-in floppy drive or optional external SCSI hard drive (max 80MB with KW-30 interface)
  • Operating system loaded from disk on power-on
  • Dimensions: 1014 x 106 x 301 mm
  • Weight: 9.8 kg
  • Built-in power supply
  • Included accessories: SYS-W30-6 W-30 System Diskette (2DD), X6-W30-01 W-30 Data Disk-1, X6-W30-02 W-30 Data Disk-2, X6-W30-03 W-30 Data Disk-3, Roland power cable (2-pin)
  • Recommended accessories: Floppy DD memory, KW-30 SCSI-Connection Board
