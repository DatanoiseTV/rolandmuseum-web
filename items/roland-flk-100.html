Roland FLK-100

Guitar FX Year: 1982

Description

The Amdek FLK-100 Flanger Kit is a DIY effects unit with four controls (Manual, Depth, Rate, and Resonance) providing a wide range of flanger effects. It features bucket-brigade memory for stability and is housed in a high-quality metal casing.

Features

  • Manual, Depth, Rate, Resonance controls
  • Bucket-brigade memory
  • Effect changeover switch
  • Effect indicator
  • Input and output terminals
  • External power source
  • Delay time: 1ms - 13ms
  • LFO speed: 100ms - 16s
  • Residual noise: -95dB (IHF-A)
  • Input impedance: 470 kOhm
  • Output load impedance: Over 10 kOhm
  • Power source: 006P battery or external power source
  • Current consumption: 15mA (DC 9V)
  • Dimensions: 95 x 64 x 143 mm
  • Weight: 520g
