Roland PG-800 Programmer

Synthesizer Programmer Year: 1984

Description

The PG-800 is a dedicated programmer device featuring sliders, buttons, and switches for hands-on sound programming of compatible Roland synthesizers such as the JX-8P, JX-10, MKS-70, or GR-77B. It connects to the synthesizer via a special 6-pin DIN cable to facilitate sound editing and parameter adjustments.

Features

  • Programmer for Roland JX-8P, JX-10, MKS-70, GR-77B
  • Device with sliders, buttons, and switches for parameter control
  • Programming accomplished via a special 6-pin DIN cable
  • Dimensions: 265 x 27 x 215 mm
  • Powered via the 6-pin DIN cable from the connected synthesizer
