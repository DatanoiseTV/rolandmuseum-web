Boss Boss NS-2 Noise Suppressor

Guitar Effects Pedal Year: 1987

Description

The Boss NS-2 Noise Suppressor eliminates unwanted noise often accumulated from using multiple effects pedals, while preserving the original tone's characteristics and nuances. Unlike traditional noise suppressors, the NS-2 adjusts decay according to the input signal level, resulting in effective noise reduction with a natural-sounding, smooth decay. A send/return loop prevents threshold level changes, providing stability in any setup. It features a DC OUT to power other pedals and a MUTE switch for silent on-stage tuning.

Features

  • Noise reduction
  • Dynamic filter
  • Send/Return loop
  • DC output
  • Mute switch
