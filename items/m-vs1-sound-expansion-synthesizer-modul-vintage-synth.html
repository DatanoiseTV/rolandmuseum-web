Roland M-VS1 Sound Expansion Synthesizer-Modul "Vintage Synth"

Sound Expansion Module Year: 1995

Description

The M-VS1 is an 8-part multitimbral sound module designed for sounds of older keyboard classics. It is based on the sound engine of the JV-80 but exclusively contains special waveforms for 'Vintage Synthesizers,' which are identical to the SR-JV80-04 Wave Expansion board. The M-VS1 can be operated in either Patch mode or Performance mode. In Patch mode, only one part is active, while in Performance mode, all eight are active, with the eighth part designated for a rhythm set. The MIDI channel can be set for each part. The M-VS1 does not have USER Patches but its sound can be altered via SysEx data. A patch consists of up to four tones, each with a dynamic filter and amp, two LFOs, and three envelope generators, with two tones being linked via 10 possible structures.

Features

  • 8-part multitimbral sound module
  • Based on JV-80 sound engine
  • Special waveforms for 'Vintage Synthesizers'
  • Identical to SR-JV80-04 Wave Expansion board
  • Patch mode or Performance mode operation
  • Performance mode: 8 active parts, 8th part for rhythm set
  • MIDI channel configurable per part
  • No user patches
  • Sound alterable via SysEx data
  • Up to four tones per patch
  • Dynamic filter and amplifier per tone
  • Two LFOs per tone
  • Three envelope generators per tone
  • Two tones linked via 10 possible structures

  • Weight: 2.65 kg
  • Power consumption: 10W
  • Integrated power supply
