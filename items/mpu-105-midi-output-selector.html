MPU-105 MIDI Output Selector

Utility Year: 1985

Description

The MPU-105 MIDI Output Selector is a MIDI-Thru box in a 1/2 19" housing. The signal from the MIDI IN jack can be routed to 5 MIDI THRU ports, which can be individually switched on or off. A red LED indicates power supply (via PSA-series AC adapter), and a green LED indicates incoming MIDI data. Furthermore, LEDs show which MIDI THRU jacks (1 to 5) are active. Unlike the MPU-104, the MPU-105 cannot be reversed in function or operated without a power supply. The MPU-105 was initially intended to be named MI-50 but was only released under the designation MPU-105.

Features

  • MIDI Thru Box Functionality
  • 1/2 19" Rackmount Format
  • 1 MIDI IN Port
  • 5 MIDI THRU Outputs
  • Individual On/Off Switches for Each THRU Port
  • Red LED for Power Indication
  • Green LED for MIDI Data Reception
  • LEDs for Active THRU Ports (1-5)
  • Requires BOSS PSA Power Adapter
  • 50mA Power Consumption
