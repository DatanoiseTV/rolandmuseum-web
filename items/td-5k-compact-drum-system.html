TD-5K Compact Drum System

Drum Sets Year: 1995

Description

The TD-5K is an almost complete drum set, assembled from the following individual components: TD-5 trigger module, KD-5 kick trigger, 5 x PD-5 snare/tom/cymbal/hi-hat triggers (rubber pads), and FD-7 hi-hat control pedal. For a ready-to-play set, a bass drum pedal, a drum stool, and a drum stand (rack with pad and cymbal holders from the MDS series or individual stands) are additionally required.

Features

  • TD-5 Module
  • 5x PD-5 Pads (Snare/Tom/Cymbal/Hi-Hat Triggers)
  • KD-5 Kick Trigger
  • FD-7 Hi-Hat Control Pedal
  • MDH-7 Pad Holders
  • Connection Cables
  • Optional MDS-7 Drum Stand with Pad/Cymbal Holders
  • Optional MDY-7 Cymbal Holder
  • Optional MDS-2 Drum Stand with Pad/Cymbal Holders
  • BRA power adapter
