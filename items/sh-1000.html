Roland SH-1000

Analog Synthesizer Year: 1973

Description

The SH-1000 is the first synthesizer built by Roland, naturally analog and monophonic. You can choose one of 10 fixed preset sounds or manually adjust the sound. There is no memory for custom settings. The sound generation uses one VCO, followed by a VCF (low-pass with resonance) and a VCA. It features an ADSR envelope generator and three fixed curves for the VCA. A headphone jack, audio effects, or CV/Gate connections are not present.

Features

  • First synthesizer built by Roland
  • Analog and monophonic architecture
  • 10 fixed preset sounds
  • Manual sound adjustment
  • No memory for user settings
  • Sound generation with one VCO
  • VCF (Low-pass filter with resonance)
  • VCA
  • ADSR envelope generator
  • Three fixed curves for the VCA
  • No headphone jack
  • No audio effects
  • No CV/Gate connections
  • Dimensions (W x H x D): 865 x 150 x 260 mm
  • Weight: 12 kg
  • Power consumption: 8W
  • Built-in power supply, fixed power cable
