Roland MC-500MKII

MIDI Sequencer Year: 1988

Description

The Roland MC-500MKII is a song-oriented MIDI sequencer with two independent MIDI outputs and a 3.5" floppy drive. Its operating system must be loaded from disk. Resembling a calculator, it has a number pad, function keys, cursor keys, an Alpha-Dial, track buttons, and a 2-line display. The included S-MRC software provides 8 tracks, each recording all 16 MIDI channels. It has a tempo track and a rhythm track for 240 patterns with up to 32 notes each. It can hold up to 8 songs in memory (max. 100,000 events). Events can be fully edited using the Microscope function. The MC-500MKII also supports alternative operating systems and synchronizes with internal/external MIDI clocks and tape sync.

Features

  • 8-track MIDI sequencer
  • 2 MIDI outputs
  • 3.5" floppy drive
  • Tempo and rhythm tracks
  • Microscope editing
  • Tape sync
