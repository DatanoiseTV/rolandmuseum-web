Roland System 100M 110

Eurorack / Modular Year: 1979

Description

The Roland System 100M 110 is a combined VCO, VCF, and VCA module. This module combines the three main synthesizer elements: voltage-controlled oscillator (VCO), voltage-controlled filter (VCF), and voltage-controlled amplifier (VCA). In conjunction with the 140 module (ENV 1/2, LFO), it provides all necessary components for sound generation. The combination of modules 110 and 140 allows for control of each individual function. The VCO, VCF, and VCA are internally hardwired, reducing external connections. However, all internal connections are automatically interrupted when external connections are used. The 110 module can be controlled by the 140's envelope generator.
