Roland 140 System 100M, 2 Env/LFO Modul

Eurorack / Modular Year: 1979

Description

The Module 140 offers 2 envelope generators and LFOs for the System-100M. Together with Module 110, this component provides the necessary elements to produce synthesizer sounds. When used with Modules 112, 121, and 130, enough elements are available to achieve two voices simultaneously. The LFO (Voltage Controlled Low Frequency Oscillator) with built-in delay allows for delay vibrato effects. The Keyboard/Trigger switch enables phase-locking of the LFO output with the keyboard trigger impulse. The envelopes (ADSR) can be triggered either manually via a rotary knob, via trigger gate, or via an internal/external gate.

Features

  • 2 Envelope Generators (ADSR)
  • 2 Low Frequency Oscillators (LFOs)
  • Designed for Roland System-100M
  • LFOs with built-in delay for delay vibrato effects
  • Keyboard/Trigger switch for LFO phase-locking
  • Multiple triggering options for envelopes (manual, trigger gate, internal/external gate)
  • Enables two-voice operation when combined with other modules (112, 121, 130)
