Boss SCC-700C Sound Control Center

Utility Year: 1985

Description

The use of effects devices in popular music is indispensable. Flanger, echo, chorus, etc., are always present wherever music is made. The simultaneous use of different effects or the use of individual effects connected in series previously caused headaches, as did connecting various effects devices, where the order played a crucial role and uncontrollable levels/volume were a problem. This task can now be completed by the musician/sound engineer before use with the BOSS SOUND CONTROL CENTER. The new SCC-700 allows up to seven effect devices (pedals, 19-inch rack units, etc.) to be fed into its computer. The SCC-700 computer can be programmed with 32 programs, each storing: 1. The number and order of effects. 2. SUB OUT/BRANCH OUT configuration for stereo effects or separate sound processing. 3. GAIN WRITE to determine the overall program volume. This allows musicians to recall desired settings for all seven effects at the touch of a button, gaining total control without constant on-stage adjustments or reliance on others. The SCC-700 also features a remote control for all program functions and a power adapter connection for 9-volt effects. The SCC-700C Central Unit is the independently operating core of the Sound Control Center.

Features

  • Manages up to seven effect devices (compact pedals to 19-inch rack units)
  • 32 user-programmable programs
  • Each program stores effect order, SUB OUT/BRANCH OUT configuration, and overall program volume (GAIN WRITE)
  • Remote control capability for all program functions (with SCC-700F Foot Controller)
  • 9V DC Out for powering external effect devices
  • Input and Output jacks: Input, Buffer Out, Main Out, Sub Out, Remote (to SCC-700F), Send (A to G), Return (A to G), 9V DC Out
  • Program memory: 32 programs (8 programs x 4 banks)
  • Battery back-up (SUM-3 x 4, 4.5V)
  • Input impedance: 1 MOhm
  • Output load impedance: > 1 kOhm (Buffer out, Main out, Sub out)
  • Output level control: +6dB to -18dB (in 8 steps)
  • Optional SCC-700F Foot Controller with dedicated footswitches (Program 1-8, Effect-off, Manual, Bank) and display
  • Optional SCC-700B Carrying Case for central unit and up to seven compact pedals
