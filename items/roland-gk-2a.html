Roland GK-2A

Guitar/Bass FX Year: 1994

Description

The Roland GK-2A is a hexaphonic pickup with a 13-pin connection designed to be mounted on standard guitars to control 13-pin system guitar synthesizers. Unlike standard pickups, it captures each string individually, providing six separate signals. The GK-2A comprises a pickup (mounted approximately 10mm behind the bridge) and a small control unit (connected by a short cable). The control unit (attached to the guitar's surface) has a mini-jack input for the signals from the standard pickups, allowing them to be transmitted via the 13-pin cable. The unit has controls for volume and a switch for selecting between guitar, mix, and pure GK signal. This is a 13-pin device, not MIDI, that allows other devices to create MIDI signals.

Features

  • Hexaphonic pickup
  • 13-pin connection
  • separate string signals
  • Mini-jack input for standard pickups
  • Volume control
  • Guitar/Mix/GK signal switch
