Roland MKS-50 MIDI Synthesizer Modul "ALPHA"

MIDI Synthesizer Module Year: 1986

Description

The MKS-50 is a 6-voice, digitally controlled analog synthesizer module in a 19" rack-mount format, occupying 1U. It is compatible with (SysEx) data from Alpha-Juno-1 and 2. For convenient parameter editing, the PG-300 programmer can be connected via MIDI. Each voice features a DCO, a fixed high-pass filter, a dynamic low-pass filter, a dynamic amplifier, one envelope generator, and one LFO. Sounds can then be enhanced with a chorus effect. It offers 64 unchangeable presets and 64 savable user sounds. Some adjustable values have very coarse stepping.

Features

  • 6-voice polyphony
  • Digitally controlled analog synthesizer module
  • 19-inch rack-mount (1U)
  • Compatible with SysEx data from Alpha-Juno-1 and 2
  • Supports PG-300 programmer via MIDI for editing
  • Per voice: DCO (Digitally Controlled Oscillator), fixed high-pass filter, dynamic low-pass filter, dynamic amplifier, 1 envelope generator, 1 LFO
  • Built-in chorus effect
  • 64 unchangeable presets
  • 64 savable user sounds
  • Dimensions: 482 x 44 x 290 mm
  • Weight: 3.5 kg
  • Power consumption: 16W
  • Integrated power supply
