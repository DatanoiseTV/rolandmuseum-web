Roland 101 System 100, 101 Basic Unit

Analog Synthesizer Year: 1976

Description

The cornerstone of the System-100 synthesizer. This basic unit is a fully standalone, monophonic analog synthesizer equipped with a 37-key keyboard and the following synthesizer modules: VCO, Noise Generator, Audio Mixer, High Pass Filter, VCF, VCA, Envelope Generator (ADSR), LFO, Glide. Pulse width is variable. CV and GATE inputs and outputs are available.

Features

  • Monophonic analog synthesizer
  • Standalone unit
  • 37-key keyboard
  • VCO (Voltage Controlled Oscillator)
  • Noise Generator
  • Audio Mixer
  • High Pass Filter
  • VCF (Voltage Controlled Filter)
  • VCA (Voltage Controlled Amplifier)
  • Envelope Generator (ADSR)
  • LFO (Low Frequency Oscillator)
  • Glide function
  • Variable pulse width
  • CV (Control Voltage) inputs and outputs
  • GATE inputs and outputs
  • Built-in power supply
