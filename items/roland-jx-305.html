Roland JX-305

Groovebox Year: 1998

Description

The Roland JX-305 is a groove synthesizer combining an 8-part multitimbral digital synthesizer with a pattern sequencer. It has a 61-key velocity-sensitive keyboard. Essentially a keyboard version of the MC-505 Groovebox, it shares the same preset patterns and sounds. Sound generation is based on the 4-tone, 10-structure architecture of the JV/XP series, but with ROM samples replaced by dance-oriented sounds. The sequencer is pattern-based, with 8 tracks fixed to parts (and MIDI channels 1-7 and 10). During playback, tracks can be individually muted, and the MEGAMIX function lets you swap tracks from the current pattern with those from other patterns. An arpeggiator and RPS sequencer can be used additionally.

Features

  • 61-key velocity-sensitive keyboard
  • 8-part multitimbral
  • Pattern-based sequencer
  • 4-tone, 10-structure architecture
  • Dance-oriented sounds
  • MEGAMIX function
  • Arpeggiator
  • RPS sequencer
