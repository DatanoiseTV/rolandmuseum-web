Boss AW-3 Dynamic Wah

Generated Guitar FX Year: 1991

Description

The BOSS AW-3 Wah pedal uses a digital processor instead of an analog circuit. This allows for a variety of classic and modern Wah-Wah sounds, such as Touch-Wah, Auto-Wah and "Humanizer". For the classic pedal-Wah sound, an expression pedal can be connected, and for bassists there is a special bass input to play the popular BOSS Touch-Wah sound. Five different modes are available: Touch-Wah with "Up" or "Down" filter movement, new "Envelope Processing" for the most accurate evaluation of playing strength, Autowah with tap tempo via the AW-3 itself or tempo setting via external expression pedal, "Humanizer" lets the guitar/bass "speak" in five selectable vowels (!), two vowels can be blended via expression pedal, classic pedal-Wah via external expression pedal, and a special input for bass.

Features

  • Digital processor
  • Touch-Wah
  • Auto-Wah
  • Humanizer
  • Expression pedal input
  • Bass input
