Roland MC-4B

Sequencer Year: 1981

Description

The MC-4B is a digital CV/Gate sequencer with 4 independent tracks. Sequences can be programmed step-by-step or played in using a CV/Gate keyboard. It offers two-stage input (pitch, then step width) and allows editing of all entries. Each track has two control voltages (CV-1 and CV-2), gate, and a trigger signal ("MPX") for controlling aspects like portamento or filter on a connected synthesizer. It features DIN-SYNC and tape sync capabilities for synchronization with other devices. Data must be saved to tape before power down. The MC-4B had 48kB of internal memory (compared to 16kB in the MC-4A).

Features

  • 4 independent tracks
  • Step-by-step programming
  • CV/Gate input
  • Two-stage input (pitch, step width)
  • Two control voltages per track
  • Gate and trigger signals
  • DIN-SYNC
  • Tape sync
  • External tempo control
  • 48kB internal memory (MC-4B)
  • Data cassette recorder interface
