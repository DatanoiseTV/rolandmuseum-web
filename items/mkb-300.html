Roland MKB-300

MIDI Master Keyboard Year: 1984

Description

The MKB-300 is a 2-zone MIDI master keyboard with 76 weighted, velocity-sensitive keys and channel aftertouch. Each zone, called UPPER and LOWER, has two buttons with which the MIDI channel can be increased or decreased and displayed on the respective 7-segment display. Very clear. The MKB-300 can be operated in WHOLE, SPLIT, or DUAL mode. Program changes can be generated manually or saved together with the mode for each of the two zones as a patch, which are sent when recalled. 128 patches can be stored internally or on an M-64C cartridge. The MKB-300 outputs performance data via four parallel MIDI OUT jacks, with data arriving at the MIDI IN jack being merged (Merge function). A MIDI THRU jack for exclusively forwarding MIDI IN data is also present. The functions of the MKB-300 are identical to the MKB-1000, but the latter has 88 wooden keys. The MKB-300 and MKB-1000 were the first dedicated master keyboards ever and, together with the MKS-10, MKS-30, and MKS-80 modules, marked the beginning of separating MIDI data and sound generation.

Features

  • 2-zone MIDI master keyboard
  • 76 weighted, velocity-sensitive keys
  • Channel aftertouch
  • 7-segment display for MIDI channel
  • WHOLE, SPLIT, or DUAL modes
  • Program change capabilities
  • 128 storable patches
  • M-64C cartridge support
  • Four parallel MIDI OUT jacks
  • MIDI IN with Merge function
  • MIDI THRU jack
