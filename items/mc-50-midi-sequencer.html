MC-50 MIDI Sequencer

Sequencer Year: 1990

Description

The MC-50 is a compact, song-oriented MIDI sequencer with 2 independent MIDI outputs, a 3.5" floppy drive, and a backlit display. Unlike its predecessors (MC-500/MKII), the main operating system does not need to be loaded from disk; the 8-track S-MRC sequencer and the Super-MRP Performance Package program are already integrated, making the MC-50 immediately ready for use. However, the MC-50 cannot directly process Standard MIDI Files (SMF) or bulk dumps from other devices, which is why it can be fed alternative operating systems from disk (MRB-500 Bulk Librarian or MRM-500 SMF-Converter). In normal operation, the MC-50 is an 8-track sequencer, with all 16 MIDI channels recordable on each track. Additionally, a rhythm track is available, on which up to 240 rhythm patterns with up to 32 different note numbers each can be arranged. These patterns can also be created by the user. The MC-50 can hold up to a maximum of 8 songs in memory, provided the memory space (approx. 40,000 events) is sufficient. With the Microscope function, all entries (events) can be fully edited. The MC-50 can be synchronized internally or externally via MIDI Clock signals, as well as via an FSK signal (tape sync) to tape machines. The MC-50 needs to convert floppy disks and songs from its predecessors MC-500, MC-300, and MC-500MKII and cannot play them directly. Reverse conversion of MC-50 songs to MC-300/500(MKII) songs is not possible.

Features

  • 2 Independent MIDI Outputs
  • 3.5" Floppy Drive
  • Backlit Display
  • Integrated 8-Track S-MRC Sequencer
  • Integrated Super-MRP Performance Package Program
  • Dedicated Rhythm Track (up to 240 patterns, 32 note numbers each)
  • Stores up to 8 Songs (approx. 40,000 Events)
  • Microscope Function for Full Event Editing
  • Internal or External MIDI Clock Synchronization
  • FSK (Tape Sync) Synchronization
  • Includes ACI Power Supply, Floppy DD Memory, MSC MIDI Cable
  • Supports optional MF-2DD Disks and DP-2 Footswitch
