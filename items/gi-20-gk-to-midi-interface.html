GI-20 GK-to-MIDI Interface

Utility Year: 2003

Description

The Roland GI-20 is a Guitar/Bass-To-MIDI interface for guitars or basses with a 13-pin connector and GK-Pickup (GK-2, GK-3, GK-2B, GK-3B, etc.) in a 9.5-inch housing (half-width, 1U 19-inch rack compatible). A switch on the back determines whether the GI-20 expects GK signals from a bass or a guitar. A GK-Pickup is required in any case. Global settings allow saving four sensitivity settings for how the GI-20 reacts to individual strings. Further settings can be stored in 50 patch memories for complex assignments at once. Per string, the pitch can be transposed from -36 to +24 semitones, the bend range can be adjusted, and it can be determined whether the string outputs data at all. MIDI base channel, poly or mono mode, 6 fingerpicking modes, and controller assignments (rear-connectable expression pedal, footswitches 1 and 2, Volume, and S1/S2 buttons on the GK-Pickup) are also stored per patch. A tuner is built-in, with its reference pitch adjustable from 427.6 Hz to 452.8 Hz in 0.2 Hz steps. Via a Bulk Dump (memory transfer), all patch settings can be output together as SysEx data via MIDI OUT, recorded with an external sequencer, and later reloaded via MIDI IN. Additionally, a USB-MIDI interface for Windows 98/Me/2000/XP and Mac OS 8.5 to 9 is built-in, which can be used instead of the MIDI jacks, allowing direct input into a similarly equipped computer. The Guitar-to-MIDI conversion is fast, even faster than the GI-10, but still has noticeable latency, especially for low notes.

Features

  • Guitar/Bass-to-MIDI interface
  • 13-pin connector for GK-Pickup (GK-2, GK-3, GK-2B, GK-3B required)
  • Switch for guitar or bass input
  • 4 global sensitivity settings for individual strings
  • 50 patch memories
  • Per-string pitch transposition (-36 to +24 semitones)
  • Per-string bend range adjustment
  • MIDI base channel, poly/mono mode, 6 fingerpicking modes
  • Assignable controllers (expression pedal, footswitches 1/2, Volume, S1/S2 on GK-pickup)
  • Built-in tuner (427.6 Hz to 452.8 Hz in 0.2 Hz steps)
  • Bulk Dump via MIDI OUT for patch settings
  • USB-MIDI interface (Windows 98/Me/2000/XP, Mac OS 8.5-9)
  • Noticeable latency, especially for low notes
  • Half-rack 1U 19-inch compatible housing
