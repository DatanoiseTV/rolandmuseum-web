Roland System 100M, 172 Phase Shifter/Audio Delay/Gate Delay

Modular Synthesizer Module Year: 1979

Description

Module 172 is a System 100M module featuring a phase shifter, audio delay, and gate delay. The phase shifter and audio delay are used for spatial effects. Combining them creates a flanger effect. Both have an on/off switch and are voltage controllable. A built-in control LFO provides normal and inverted outputs. The gate delay can delay gate signals and shorten gate impulses. It also has an amplifier, allowing gate impulses recorded on tape to be used to trigger various synthesizer functions, enabling seamless sequencing on multi-track recorders.

Features

  • Phase shifter, audio delay, and gate delay
  • Voltage controllable phase shifter and audio delay
  • Built-in control LFO
  • Gate delay with amplifier for triggering functions
