CS-1 Compression Sustainer

Guitar/Bass FX Year: 1980

Description

The CS-1 Compression Sustainer is a compressor unit that achieves clear and undistorted tone extensions. Its wide compression range and high input level allow it to be used with any instrument. Controls on the CS-1 include volume level, sustain time, and a selector switch for Normal/Treble boost. The volume level control balances the effect/normal output volume so that there are no volume differences when switching between normal and effect. The sustain control determines the compression level. Turning this knob clockwise to the stop provides the longest sustain value. Moving it in the opposite direction limits the output level. This is extremely useful for giving guitar or bass that extra bite. An interesting feature of the CS-1 is the selector switch, which chooses between normal and treble boost to, for example, emphasize higher frequency components in the sustain.
