Roland S-550 Sampler Module

Sampler Year: 1987

Description

The S-550 is a 16-voice digital sampler module in a 2U rack format with a 3.5-inch floppy drive for sample storage. It is Roland's rack version of the S-50 keyboard sampler, offering double the memory and dynamic filters. The memory holds a maximum of 4 x 7.2 seconds of samples, divided into 2 blocks with 2 banks each (A and B). The S-550 samples at 12-bit with a selectable rate of 15 or 30kHz, but sounds excellent thanks to its superb 16-bit converters. The foundation of the sound consists of up to 64 raw samples, which are assigned playback parameters to become 'Tones'. Tones can be freely assigned across the keyboard and saved as a Patch (sound program). The S-550 allows for 32 patches. The single-line display is not ideal for editing, but a monitor and mouse, as well as a tablet for drawing waveforms (DT-100), can be connected. The operating system must be loaded from a floppy disk upon startup. The S-550 can be upgraded with an HD5-IF SCSI interface, to which a maximum 80MB (yes, Megabyte!) Apple-compatible SCSI hard drive or the CD-5 CD-ROM drive can be connected. With the optional, hardware-dongle-protected DIRECTOR-S software SYS-553, the S-550 can be transformed into a multi-track MIDI sequencer.

Features

  • 16-voice digital sampler module
  • 2U rackmount unit
  • 3.5-inch floppy drive for sample storage
  • Double the memory and dynamic filters compared to S-50
  • Max memory: 4 x 7.2 seconds samples (2 blocks, 2 banks each)
  • 12-bit sampling resolution
  • Selectable sampling rates: 15kHz or 30kHz
  • 16-bit D/A converters
  • Supports up to 64 raw samples
  • 32 patch memory locations
  • Connectable to external monitor and mouse
  • Connectable to DT-100 tablet for waveform drawing
  • Operating system loaded from floppy disk
  • Optional HD5-IF SCSI interface for up to 80MB SCSI hard drive or CD-5 CD-ROM drive
  • Optional DIRECTOR-S software SYS-553 (with hardware dongle) for multi-track MIDI sequencer functionality
  • Dimensions: 482 x 88 x 400 mm
  • Weight: 7.7 kg
  • Built-in power supply
