Roland SP-808EX e Mix Studio, Phrase Sampler/HD-Recorder

Phrase Sampler and HD Recorder Year: 2000

Description

The Roland SP-808EX e-Mix Studio is an all-in-one phrase sampler and hard disk recorder, designed for music production with integrated effects and mixing capabilities.

Features

  • Phrase Sampler
  • Hard Disk Recorder
  • e-Mix Studio functionality
  • Built-in power supply
  • Dimensions (394 x 100.5 x 343 mm)
  • Weight (4.3 kg)
  • Supports 250MB ZIP media for storage (recommended)
  • Optional XLR/digital I/O board (SP-808-OP2)
  • Optional individual outs and SCSI board (SP-808-OP1)
