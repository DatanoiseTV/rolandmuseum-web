Roland S-330 19" Sampler Module

Sampler Year: 1988

Description

The S-330 is a 16-voice digital sampler module with 1U rack size and a 3.5-inch floppy drive for sample storage. Essentially, the S-330 is the module counterpart to the S-50 keyboard sampler; while the S-330 has dynamic filters, it only has one memory, exactly like the S-50, unlike the S-550. The memory holds a maximum of 2 x 7.2 seconds of samples, divided into banks A and B. The S-330 samples at 12-bit with a selectable rate of 15 or 30kHz, but sounds excellent thanks to its superb 16-bit converters. The sound basis consists of a maximum of 32 pure samples, which are assigned playback parameters to become "Tones". Tones can be freely distributed across the keyboard and saved as a Patch (sound program). The S-330 allows for 16 patches. The small display is not inviting for editing, but a monitor, mouse, and a tablet for drawing waveforms (DT-100) can be connected. The operating system must be loaded from a floppy disk at startup. The S-330 has no option for a SCSI interface but can also transform into a multi-track MIDI sequencer using the optional, hardware-dongle-protected DIRECTOR-S software SYS-333.

Features

  • 16-voice digital sampler module
  • 1U rack format
  • 3.5-inch floppy drive for sample storage
  • Dynamic filters
  • Maximum 2 x 7.2 seconds of samples
  • Memory divided into banks A and B
  • 12-bit sampling at selectable 15 or 30kHz
  • 16-bit converters
  • Maximum 32 pure samples
  • 16 patches storable
  • Connectivity for monitor, mouse, and DT-100 tablet
  • Operating system must be loaded from floppy disk
  • No SCSI interface option
  • Optional multi-track MIDI sequencer via DIRECTOR-S software SYS-333
  • Dimensions: 482 x 44 x 340 mm
  • Weight: 4.3 kg
  • Built-in power supply
