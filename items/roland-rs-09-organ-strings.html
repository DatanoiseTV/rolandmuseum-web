Roland RS-09 Organ-Strings

Analog Synthesizer Year: 1978

Description

The RS-09 'Organ Strings 09' is a 44-key analog keyboard combining an organ and a string ensemble in a compact housing. The keyboard is not velocity-sensitive. The string section offers two footages (8' and 4') and an attack time control. The organ section offers 4 controls for mixing footages (16', 8', 4', and 2'). In each section, the ensemble effect can be switched on/off, and the decay can be adjusted with the common Release control. There is also a common Vibrato control, a Tone control for sound shaping, and a selector switch for Ensemble I or II. On the rear panel, there are stereo outputs, a stereo headphone jack, a separate mono organ output, and a gate control output. A sustain pedal input and an audio input for using the ensemble effect with external sound sources are also present. Like the VP-330, there was an early version with grey rocker switches and later with illuminated, colorful buttons, known from the Jupiter-8.

  • Switchable Ensemble effect for each section

  • Built-in power supply
