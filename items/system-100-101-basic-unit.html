Roland System 100, 101 Basic Unit

Modular Synthesizer Year: 1976

Description

The Roland System 100, 101 Basic Unit serves as the foundation of the System 100 modular synthesizer. This self-contained, monophonic analog synthesizer features a 37-key keyboard and includes the following modules: VCO, noise generator, audio mixer, high-pass filter, VCF, VCA, ADSR envelope generator, LFO, and glide. It offers variable pulse width and includes CV and Gate inputs and outputs.

Features

  • 37-key keyboard
  • Monophonic
  • VCO

  • Audio mixer
  • High-pass filter

  • VCA
  • ADSR envelope generator
  • LFO
  • Glide
  • Variable pulse width
  • CV/Gate I/O
