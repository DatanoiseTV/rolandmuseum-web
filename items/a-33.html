Roland A-33

MIDI Master Keyboard Year: 1996

Description

This velocity-sensitive master keyboard for 2 zones features 76 (plastic) keys, providing a 6-octave range, and channel aftertouch. It offers 32 patches for storing control and program changes for GS sounds, a combined pitch bend/modulation lever, and can be battery-powered. Connections for expression and sustain pedals are available.

Features

  • Velocity-sensitive master keyboard
  • 2 zones
  • 76 (plastic) keys
  • 6-octave range
  • Channel aftertouch
  • 32 patches for storing control and program changes for GS sounds
  • Combined pitch bend/modulation lever
  • Battery-powered (6 x 1.5V AA/LR6)
  • Connections for expression and sustain pedals
