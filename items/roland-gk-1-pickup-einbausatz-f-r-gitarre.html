Roland GK-1 Pickup Einbausatz für Gitarre

Guitar/Bass FX Year: 1986

Description

The Roland GK-1 is a hexaphonic pickup with a 24-pin connector for mounting on standard guitars to control guitar synthesizers of the 24-pin system. Unlike normal pickups, the hexaphonic pickup picks up all strings individually, so that six signals are available. The GK-1 consists of the actual pickup, which should be mounted about 10mm behind the bridge, and a control box, which is connected via a short cable. The control box, which is fixed to the guitar surface with a special bracket on the strap button, has a jack input to connect the signal from the normal pickups so that this is also transmitted via the 24-pin cable. The four controls of the control box are for the overall volume, the ratio of normal pickup and synthesizer signal, and 2 control signals. The 24-pin cable is permanently connected to the control box.

Features

  • Hexaphonic pickup
  • 24-pin connector
  • Control box for volume, mix, and control signals
  • Compatible with 24-pin guitar synthesizers
