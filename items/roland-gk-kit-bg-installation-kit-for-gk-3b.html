Roland GK-KIT-BG Installation Kit for GK-3B

Synthesizer Addons Year: 2007

Description

The Roland GK-KIT-BG is an installation kit for a hexaphonic pickup that can be built into a bass guitar using milling and soldering work to control bass synthesizers or virtual bass systems of the 13-pin system. The pickup bar should be mounted approximately 10mm behind the bridge and is connected with a short cable to the control electronics, which must be installed inside the bass body. Holes should also be made accessible for the two 'S1' and 'S2' buttons, the switch from BASS to MIX to GK only, and the 13-pin jack for connecting the GK cable. This installation kit does not yet provide MIDI signals, as is sometimes incorrectly assumed, but is a prerequisite for a 13-pin device (e.g., V-Bass, GR-20, GI-20, VB-99, etc.) to convert them into MIDI signals. Compared to the GK-2B, the shape of the control unit and the pickup has slightly changed.

Features

  • Installation kit for hexaphonic pickup
  • Designed for bass guitars
  • Enables control of 13-pin bass synthesizers or virtual bass systems
  • Requires milling and soldering for installation
  • Pickup bar mounts ~10mm behind the bridge
  • Includes control electronics for internal bass body installation
  • Provides 'S1' and 'S2' buttons
  • Switch for BASS / MIX / GK-only modes
  • 13-pin jack for GK cable connection
  • Does not generate MIDI signals directly, but provides input for devices that do
  • Successor to GK-2B with slight form changes
