M-VS1 Sound Expansion Synthesizer Module "Vintage Synth"

Digital Synthesizer Year: 1995

Description

The M-VS1 is an 8-part multitimbral sound module for sounds of older keyboard classics. It is based on the sound generation of the JV-80 but contains only special waveforms for "Vintage Synthesizers," which are identical to the SR-JV80-04 Wave Expansion Board. The M-VS1 can be operated in either Patch Mode or Performance Mode. In Patch Mode, only one part is active; in Performance Mode, all eight are active, with the eighth part intended for a rhythm set. The MIDI channel can be set for each part. The M-VS1 has no USER patches but can be modified via SysEx data. A patch consists of up to four tones, each with a dynamic filter and amp, two LFOs, and three envelopes, with two tones linked via 10 possible structures.

Features

  • 8-part multitimbral sound module
  • Specialized in "Vintage Synth" sounds
  • Based on JV-80 sound generation
  • Waveforms identical to SR-JV80-04 Wave Expansion Board
  • Patch Mode (single part active) and Performance Mode (all 8 parts active)
  • Eighth part dedicated to rhythm set in Performance Mode
  • MIDI channel assignable per part
  • No user patches, but editable via SysEx data
  • Patch structure: up to four tones
  • Tone components: dynamic filter, amp, two LFOs, three envelopes
  • Two tones linked via 10 possible structures
  • Integrated power supply
  • Dimensions: 482 x 44 x 165 mm
  • Weight: 2.65 kg
