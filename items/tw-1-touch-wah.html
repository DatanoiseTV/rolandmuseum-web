Boss TW-1 Touch Wah

Compact Effect Pedal Year: 1980

Description

Just as the Slow Gear is a significant enrichment for guitarists, the Touch Wah is an effect pedal that bassists should not do without. The Touch Wah is a touch-sensitive wah-wah.

Features

  • Touch-sensitive wah-wah effect
  • Sens (Sensitivity) control
  • Peak (Wah-Wah range) control
  • Drive Down/Up switch for effect direction
  • Power: 9V Battery or AC Adapter
  • Current draw: DC9V, 6mA
  • S/N ratio: Over 80dB
  • Input impedance: 220K Ohm
  • Output load impedance: Over 10K Ohm
