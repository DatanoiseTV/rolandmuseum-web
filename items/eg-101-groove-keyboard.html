Roland EG-101 Groove Keyboard

Groove Arranger Keyboard Year: 1999

Description

The EG-101 is a Groove Arranger keyboard with 49 velocity-sensitive keys, a D-Beam Controller, and an arpeggiator. The sound engine offers 12 unchangeable drum kits and 448 dance sounds, where only filter cutoff and resonance can be altered, along with audio effects. The arranger provides 64 styles, each with four variations; alternatively, 64 * 8 RPS phrases can be used as accompaniment. A small, lower-quality sampler is also on board. The 2 x 15 Watt amplification with a 2-way bass-reflex system sounds surprisingly good. While variations in the sound character can be created, unfortunately, the note sequences of styles and RPS phrases cannot be altered.

Features

  • 49 velocity-sensitive keys
  • D-Beam Controller (36 different effects)
  • Sampler (with separate volume control)
  • RPS (Hundreds of Dance Phrases)
  • Three operating modes: RPS, Arranger, Whole Keyboard
  • 448 fat dance sounds & 12 drum kits
  • 64 styles (each with 4 variations)
  • Audio and MIDI Auto Sync
  • Arpeggio, Portamento
  • Realtime EFX effects (also for Line/Mic In)
  • Microphone input
  • 128 user memories (64 for Arranger + 64 for RPS)
  • 2-track recorder
  • Tap Tempo function
  • 2 x 15 Watt amplification
  • 2-way bass-reflex system + Low Boost
  • Connections: RCA Output (L/R), RCA Input (L/R), Footswitch, Headphones, MIDI In/Out, DC In
