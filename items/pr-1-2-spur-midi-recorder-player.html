Roland PR-1 2-Spur-MIDI-Recorder/Player

MIDI Recorder/Player Year: 1991

Description

The PR-1 is a simple 2-track MIDI sequencer without editing functions but with an integrated library of piano pieces for practice. For personal recordings, approximately 4000 events of memory space are available. Only 1 custom song can be recorded, and data backup is not provided. However, data is retained after powering off (provided the buffer battery still has charge). A metronome can be activated with time signatures of 1-4 half notes, 1 to 8 quarter notes, or 1 to 9 eighth notes, and the tempo can be set from 10 to 250 BPM.

Features

  • Simple 2-track MIDI sequencer
  • No editing functions
  • Integrated library of piano pieces for practice
  • Memory for approximately 4000 events
  • Only 1 custom song can be recorded
  • No data backup provided
  • Data retained after power-off (buffer battery)
  • Metronome with time signatures: 1-4 half notes, 1-8 quarter notes, 1-9 eighth notes
  • Tempo adjustable from 10 to 250 BPM
  • Dimensions: 174 x 65 x 142 mm
  • Battery operation: 9V block (6LR61)
  • Power consumption: 40mA
  • BOSS PSA power adapter compatible
  • Included accessories: 006P 9V block battery, 2x MSC MIDI cables
