Roland MKS-900 MIDI Signal Indicator

MIDI Utility Year: 1985

Description

The Roland MKS-900 MIDI SIGNAL INDICATOR is a 1U rack-mount LED display for MIDI note data, visually arranged like a keyboard. The MKS-900 shows the full note range of an 88-key piano (A1 to C8). This allows for easy monitoring of MIDI messages such as note on/off, program change, and sustain pedal. The MKS-900 has one MIDI input and 5 parallel MIDI OUT connections. In addition to its valuable monitoring function, the MKS-900 allows you to choose whether all or only the data of a single, adjustable MIDI channel are output via MIDI OUT. The MKS-900 can therefore also serve as a MIDI filter and/or THRU box.

Features

  • LED display visually arranged as a keyboard
  • Displays MIDI note data
  • 1U rack-mount format
  • Shows full 88-key piano range (A1 to C8)
  • Monitors MIDI messages: note on/off, program change, sustain pedal
  • 1 MIDI input
  • 5 parallel MIDI OUT connections
  • Functions as a MIDI filter (selectable MIDI channel output)
  • Functions as a MIDI Thru box
  • Dimensions: 482 x 45 x 180 mm
  • Weight: 2.5 kg
  • Internal power supply
