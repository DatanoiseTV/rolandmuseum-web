Roland System 100M, 2 Env/LFO Modul

Modular Synthesizer Year: 1979

Description

The Roland System 100M Model 140 is a two-part envelope generator and LFO module. Along with the 110 oscillator, it provides core synthesis functions. When used with the 112, 121, and 130 modules, it facilitates dual-voice synthesis. The LFO features built-in delay for vibrato effects, and phase-locking to keyboard trigger signals. Envelopes are triggerable manually, via gate, or internally/externally.

Features

  • Dual envelope generators
  • Dual LFOs
  • Delay for LFO
  • Keyboard/trigger switching for LFO
  • Manual and gated envelope triggering
