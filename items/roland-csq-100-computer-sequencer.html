Roland CSQ-100 Computer Sequencer

Sequencer Year: 1979

Description

The CSQ-100 is a digitally controlled sequencer for analog CV/Gate signals. It offers memory for 2 sequences of 84 steps (notes) each, which can be played independently or chained, once or repeatedly. A CV input for transposition is available, as are START and STEP output jacks. Step duration and CV voltages can be programmed separately in two passes. Recorded sequences are temporarily backed up by a battery even after power-off; there is no option to permanently save sequences. The CSQ-100 is Roland's first sequencer whose steps could only be entered or played via a CV/Gate keyboard. At the time, the MC-8 (later replaced by the MC-4) existed for programming, and module 182 for adjusting individual steps. The CSQ-100 was directly followed by the larger CSQ-600, after which the concept was consistently implemented for new control technologies, first DCB, then MIDI, leading to the JSQ-60 and MSQ-100 models.

Features

  • Digitally controlled sequencer for analog CV/Gate signals
  • Memory for 2 sequences of 84 steps each
  • Sequences can be played independently or chained
  • Sequences can be played once or repeatedly
  • CV input for transposition
  • START and STEP output jacks
  • Separate programming for step duration and CV voltages
  • Battery backup for volatile sequence memory (no permanent save)
  • First Roland sequencer with CV/Gate keyboard input for steps
