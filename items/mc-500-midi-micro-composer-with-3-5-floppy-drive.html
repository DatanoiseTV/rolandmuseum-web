MC-500 MIDI Micro-Composer with 3.5" Floppy Drive

Sequencer Year: 1986

Description

The MC-500 is a song-oriented MIDI sequencer with 2 independent MIDI outputs and a 3.5-inch floppy drive, whose operating system must be loaded from a disk at startup. The hardware, with its numeric keypad and overall design, strongly resembles a calculator and feels excellent to operate. It features 6 drive buttons, 7 function buttons, 2 cursor buttons, an alpha-dial for value input, 5 illuminated track buttons, and an unfortunately non-backlit 2-line display for operation. Originally, the MC-500 shipped with MRC-500 software, turning it into a 4-track sequencer, where all 16 MIDI channels can be recorded on each track. Additionally, besides a tempo track, there's a rhythm track available, on which up to 90 rhythm patterns with up to 32 different note numbers each can be arranged. These patterns can also be created by the user. The MC-500 can hold up to 8 songs in memory, provided there is enough space. Using the 'Microscop' function, all entries (events) can be fully edited. Unfortunately, for various functions, the system diskette must be reinserted repeatedly, which can be somewhat annoying. However, the MC-500 can also be started with other operating systems. With the S-MRC (Super-MRC) software, the MC-500 becomes an 8-track sequencer, also with a pattern-oriented rhythm track, where 240 patterns are possible. The MRP-500 Performance Package allows the creation of stage-ready MRC-500 song sequences that can be started completely with pauses (or without) and repetitions by simple button press. The MRD-500 Rhythm Bank package provides pre-programmed patterns and software for arranging rhythm tracks, and the MRB-500 Bulk Librarian enables the management of bulk dumps from various – including non-Roland – devices. When the MC-500MKII was released, an OM-500 memory expansion became available, expanding the memory to the size of the MC-500MKII. There was also the MRM-500 software, which could convert MRC-500 and S-MRC songs to Standard MIDI Files (SMF) and vice-versa. The MC-500 with MRC-500 or S-MRC combines the advantages of all previous sequencers except analog step sequencers. The MC-500 holds a maximum of 25,000 events and can be synchronized internally or externally via MIDI Clock signals, as well as via an FSK signal (Tape Sync) to tape recorders.

Features

  • Song-oriented MIDI sequencer
  • 2 independent MIDI outputs
  • 3.5-inch floppy drive (OS loaded from disk)
  • Numeric keypad
  • 6 drive buttons, 7 function buttons, 2 cursor buttons, alpha-dial, 5 illuminated track buttons
  • Non-backlit 2-line display
  • MRC-500 software (4-track sequencer, 16 MIDI channels per track)
  • Rhythm track (up to 90 rhythm patterns, each with up to 32 note numbers)
  • Stores up to 8 songs
  • 'Microscop' function for event editing
  • S-MRC (Super-MRC) software (8-track sequencer, 240 patterns)
  • MRP-500 Performance Package
  • MRD-500 Rhythm Bank package
  • MRB-500 Bulk Librarian
  • OM-500 memory expansion (to MC-500MKII size)
  • MRM-500 software for Standard MIDI File (SMF) conversion
  • Max 25,000 events
  • Synchronizes via MIDI Clock or FSK (Tape Sync) with tape recorders
  • Dimensions: 305(W) x 91(H) x 285(D) mm
  • Weight: 3.4 kg
  • Built-in power supply
