Roland S-770 19" Professional Digital Stereo Sampler

Sampler Year: 1989

Description

The Roland S-770 is a 24-voice, 16-bit stereo sampler with a built-in 40MB hard drive, digital S/P-DIF audio connections, and mouse and monitor connectivity. Sampling frequencies of 22.05 kHz, 44.1 kHz, or 48 kHz can be used. The S-770 requires its operating system to be loaded at startup, which can be done from floppy disk, the built-in HD, or data carriers connected via the SCSI port. The S-770 can be fully operated using its built-in display and buttons, though this is somewhat cumbersome. However, a monitor (or TV with S-Video input) and a mouse (MU-1), as well as an optional remote control (RC-100), can be connected, which makes operation very comfortable. Sound generation is structured as follows: A sample includes loop points and loop mode (forward, reverse, alternating, no loop), original pitch, and fine-tuning. A maximum of 4 samples can be assigned to a Partial, which controls panorama, level, dynamic crossfading with fades, etc. Dynamic amplifiers, filters, envelopes, and LFOs are also part of the Partial. Up to 88 Partials can be distributed as non-overlapping zones across the note range (splits) and form a Patch (sound program of a part). A maximum of 32 Parts, assigned with MIDI channels and output assignments, can form a Performance. For data storage, there is also the 'Volume' concept, which groups several Performances and can be loaded into the S-770's memory at once. The factory memory is 2MB, but can be expanded to a total of 16MB by installing the RAS-770 memory expansion board, which then accommodates OMS-770 memory sticks. The S-770 is fully data-compatible with the S-750 and can also handle data from the S-760. One of these three samplers (S-750, S-770, or S-760) or the sample player SP-700 is referred to when speaking of the Roland S-700 series, for which there is a large library of samples from other manufacturers, as well as from Roland itself.

Features

  • 24-voice polyphony
  • 16-bit stereo sampler
  • Built-in 40MB hard drive
  • Digital S/P-DIF audio connections
  • Mouse and monitor (S-Video) connectivity for comfortable operation
  • Sampling frequencies: 22.05 kHz, 44.1 kHz, 48 kHz
  • Operating system loaded from floppy, internal HD, or SCSI
  • Internal display and buttons for operation
  • Sample parameters: loop points, loop mode (forward, reverse, alternating, no loop), original pitch, fine-tuning
  • Partial structure: up to 4 samples, panorama, level, dynamic crossfading, dynamic amplifiers, filters, envelopes, LFOs
  • Patch structure: up to 88 Partials as non-overlapping note zones (splits)
  • Performance structure: up to 32 Parts with MIDI channels and output assignments
  • Volume concept for grouping and loading multiple Performances
  • Factory memory: 2MB, expandable to 16MB with RAS-770 board and OMS-770 sticks
  • Data-compatible with S-750 and S-760
  • Built-in power supply
  • Dimensions: 482 x 132 x 420 mm
  • Power consumption: 40W
