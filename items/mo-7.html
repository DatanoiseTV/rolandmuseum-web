Roland MO-7

Magnetic Optical Disc Drive Year: 1989

Description

The MO-7 is a magneto-optical storage drive with SCSI connections. It features a built-in 5.25" Sony SMO-501 drive, which can process 650MB media, but Roland samplers require media with 512kB sectors, so the MO-7 offers 'only' 600MB of storage per MO disk. This 600MB is not available at once, as the media (MO disks) are double-sided, offering 300MB per side. The SCSI ID is freely adjustable, and the MO-7 is not internally terminated. Both SCSI connections are 50-pin Centronics connectors.

Features

  • Magneto-optical storage drive
  • SCSI connections
  • Built-in 5.25" Sony SMO-501 drive
  • 600MB storage capacity per MO disk (300MB per side, double-sided media)
  • Supports 512kB sectors for Roland samplers
  • Freely adjustable SCSI ID
  • Not internally terminated
  • Two 50-pin Centronics SCSI connectors
  • Dimensions: 212 x 129 x 321 mm
  • Built-in power supply
  • Included accessories: EDM-1 DA-1 MO storage medium
