Roland MKS-80 Synthesizer Module SUPER JUPITER

Analog Synthesizer Year: 1984

Description

The SUPER JUPITER MKS-80 is an 8-voice, MIDI-controlled, analog synthesizer module in a 19-inch, 2U rack format. Each voice features two oscillators, a non-dynamic high-pass filter, a dynamic 24db low-pass filter, an LFO, and two envelopes. Both oscillators provide triangle, sawtooth, and square/pulse waves (variable pulse width), can be tuned semitone-wise from 32-foot to 2-foot settings, detuned against each other, and hard-synced. OSC2 also offers white noise and "Low" and "High" tunings. A unique feature allows the pitch spread of one oscillator to be set below 100%. The low-pass filter is resonant, and the envelopes react to both velocity and keyboard position (Key Follow). The MKS-80 largely corresponds to the architecture of the Jupiter-8. A single sound program is called a "Tone," with 64 internal storage slots. The MKS-80 is 2-part multitimbral, allowing two Tones to be combined as a Split or DUAL. A combination is called a "Patch," which stores the octave range, bend behavior, playing mode (Solo, Unison, Polyphonic) of the Tones, and their volume balance. There are also 64 internal patch memory slots. An external M-64C cartridge can be inserted to provide an additional 64 Tones and 64 Patches. Furthermore, the MKS-80 can be edited via MIDI SysEx commands, although a complete dump is not possible. Since creating sounds on the MKS-80 by selecting parameter numbers and then entering values via buttons is cumbersome, the MPG-80 Programmer can be connected, which has dedicated controls for all relevant parameters. There were two versions of the MKS-80, which sound different: up to serial number 511799, the well-known Curtis chips (also used in SCI or Oberheim) were employed, after which Roland's own chips and filters were used. The three MKS modules MKS-30 (Planet-S), MKS-10 (Planet-P), and MKS-80 (SUPER JUPITER) were among the first MIDI sound modules ever and, together with the master keyboards MKB-1000 and MKB-300, marked the beginning of the separation of MIDI data and sound generation.

Features

  • 8-voice polyphony
  • MIDI-controlled
  • Analog synthesizer module
  • 19-inch, 2U rack format
  • Per voice: 2 oscillators, non-dynamic high-pass filter, dynamic 24dB resonant low-pass filter, LFO, 2 envelopes
  • Oscillator waveforms: Triangle, Sawtooth, Square/Pulse (variable pulse width)
  • Oscillator tuning: Semitone-wise, 32-foot to 2-foot settings
  • Oscillator features: Detune, Hard Sync
  • OSC2 additional waveforms: White noise, Low/High tunings
  • Pitch spread control for one oscillator (below 100%)
  • Envelopes respond to velocity and key position (Key Follow)
  • Similar architecture to Jupiter-8
  • 64 internal Tone memories
  • 2-part multitimbral (Split/Dual modes)
  • 64 internal Patch memories
  • External memory: M-64C cartridge (64 Tones, 64 Patches)
  • MIDI SysEx editing (no complete dump)
  • Optional MPG-80 Programmer for easier editing
  • Two hardware versions: early versions (up to SN 511799) used Curtis chips; later versions used Roland chips and filters
  • Dimensions: 482 x 88 x 400 mm
  • Weight: 8 kg
