Roland JX-3P

Analog Synthesizer Year: 1983

Description

The JX-3P is a 6-voice, digitally controlled analog synthesizer with 61 non-velocity-sensitive keys, a 128-step sequencer, 32 preset and 32 user sounds. Each voice has two DCOs, a resonant VCF, a dynamic VCA, a static high-pass filter, one envelope generator, and one LFO. The VCA can be switched to gate mode. Oscillators produce square, sawtooth, and pulse waves; the second can also produce noise. Hard-sync and a "metal" effect (a type of cross-modulation) add sound variety. It is an early MIDI synthesizer and only works in Omni mode by default. Data could be saved to tape, and the optional PG-200 programmer could be used for programming.

Features

  • 6-voice polyphony
  • 61 keys
  • 128-step sequencer
  • 2 DCOs per voice
  • Resonant VCF
  • Dynamic VCA
  • Static high-pass filter
  • 1 EG per voice
  • 1 LFO
  • Hard sync
  • Metal effect (cross-modulation)
  • 32 presets
  • 32 user memory locations
