Roland JU-2 JUNO-ALPHA-2

Analog Synthesizer Year: 1985

Description

The Alpha-Juno-2, or JU-2, is a 6-voice, digitally controlled analog synthesizer with 61 velocity-sensitive keys. The Alpha-Juno-2 is compatible with (SysEx) data from Alpha-Juno-1, HS-10, HS-80, and MKS-50. For convenient parameter editing, the PG-300 programmer can be connected via MIDI. Per voice, it features a DCO, a fixed high-pass filter, a dynamic low-pass filter, a dynamic amplifier, 1 envelope generator, and 1 LFO. Sounds can then be enhanced with a chorus effect. 64 immutable presets and 64 savable user sounds are available. Some adjustable values have very coarse stepping. A version with speakers for living rooms, as an accompaniment to pianos, was sold under the designation HS-80.
