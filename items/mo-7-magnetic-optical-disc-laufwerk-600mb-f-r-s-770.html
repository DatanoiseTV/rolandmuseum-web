MO-7 Magnetic Optical Disc Laufwerk 600MB für S-770

Synthesizer Addons Year: 1989

Description

The MO-7 is a magneto-optical storage drive with SCSI connections. It features the Sony 5.25-inch SMO-501 drive, which can also handle 650MB media, but Roland samplers require media with 512kB sectors, so the MO-7 "only" offers 600MB of storage space per MO disk. However, this 600MB is not available at once, as the media (MO disks) are double-sided and offer only 300MB per side. The SCSI ID is freely adjustable, and the MO-7 is not internally terminated. Both SCSI connections are implemented as 50-pin Centronics connectors.

Features

  • Magneto-optical storage drive
  • SCSI connections
  • Sony SMO-501 5.25-inch drive
  • 600MB storage per MO disk (300MB per side)
  • Requires 512kB sector media for Roland samplers
  • Freely adjustable SCSI ID
  • No internal termination
  • Two 50-pin Centronics SCSI connectors
