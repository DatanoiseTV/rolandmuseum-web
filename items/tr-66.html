Roland TR-66

Rhythm Machine Year: 1975

Description

The TR-66 rhythm machine is externally named 'Rhythm Arranger 66' and is an analog rhythm machine featuring 9 fixed rhythms selectable via push buttons and 18 additional rhythms selectable via rotary switches. Each rhythm is available in variations A and B. Rhythms from both groups can be combined, and a switch allows choosing between variation A, B, or an alternating A/B sequence (called Auto), hence the 'Arranger' moniker. The Rhythm-Arranger 66 belongs to Roland's second series of rhythm machines, alongside the TR-330 and TR-700, and is housed in a rectangular wooden case with controls on the front. On the rear, there is a mono output for high and low levels and a connection for a start button. The tempo is set with a rotary knob; synchronization is not possible.

Features

  • Analog rhythm machine
  • 9 fixed rhythms via push buttons
  • 18 additional rhythms via rotary switch
  • Rhythms available in A and B variations
  • Rhythm combination possible
  • Auto (alternating A/B) sequence mode
  • Rectangular wooden case
  • Mono output (high/low level)
  • Start button connection
  • Tempo knob (no synchronization)
  • Selectable rhythms: Waltz, Jazz Waltz, Slow Rock, Bossa Nova, Samba, Mambo, Cha Cha, Beguine, Rhumba, Rock 1-6, Bass&Snare, Foxtrot 1-2, Swing 1-3, March, Parade, Habanera, Shuffle, Tango
