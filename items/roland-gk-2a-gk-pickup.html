Roland GK-2A GK-Pickup

Synthesizer Addons Year: 1994

Description

The Roland GK-2A is a hexaphonic pickup with a 13-pin connector, designed for mounting on standard guitars. Its primary purpose is to drive guitar synthesizers that utilize the 13-pin system. Unlike conventional pickups, the hexaphonic GK-2A senses each string individually, providing six discrete signals. The unit consists of two main parts: the pickup itself, recommended for mounting approximately 10mm behind the bridge, and a small control unit connected by a short cable. This control unit, which needs to be affixed to the guitar's surface, includes a mini-jack input to connect and transmit the signal from the guitar's normal pickups via the same 13-pin cable. The control unit features two buttons ('Up/S2' and 'Down/S1'), a volume knob for the synthesizer sound, and a selector switch for Guitar, MIX, or pure GK signal, along with the 13-pin connector. The GK-2A differs from its predecessor, the GK-2, only in having a narrower pickup bar design. It is important to note that the GK-2A is not a MIDI pickup itself, but rather a necessary component that allows a compatible 13-pin device (e.g., GR-1, GR-30, GR-50, GI-10, VG-8) to generate MIDI signals.

Features

  • Hexaphonic pickup with 13-pin connector
  • Designed for mounting on standard guitars
  • Controls 13-pin system guitar synthesizers
  • Senses each string individually, providing six separate signals
  • Two-part design: pickup and control unit
  • Control unit includes mini-jack input for normal guitar pickups
  • Control unit features 'Up/S2' and 'Down/S1' buttons, synth volume control, and Guitar/MIX/GK signal switch
  • Narrower pickup bar design (compared to GK-2)
  • Prerequisite for 13-pin devices to convert signals to MIDI (not a MIDI pickup itself)
  • Power supply via GK cable
  • Included accessory: Mini-jack to standard-jack cable
  • Dimensions (control unit): 80 x 34 x 77 mm
  • Weight (pickup + control unit): 0.07 kg
