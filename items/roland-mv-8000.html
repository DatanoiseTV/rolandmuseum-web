Roland Roland MV-8000

Production Studio Year: 2003

Description

The MV-8000 is a combination of a sequencer and a sampler in a console housing with a built-in hard drive. The sequencer offers 128 tracks, on which, however, only one channel can be recorded at a time. Only from software version 3.5 onwards can patterns be used; otherwise, the sequencer is song-oriented, meaning the tracks extend over the entire length of the song. The sampler of the MV-8000 is based on the structure of the older Roland S-700 series (S-750 / 760, etc.), meaning the sampling CD-ROMs for this series can be read and directly processed by the MV-8000. A patch (sound program) consists of up to 128 'Partials' (keyboard zones), with each Partial capable of containing up to four samples that can be crossfaded using a controller or velocity. Samples can contain 1 loop, which can be played forwards, backwards, or alternating. All samples of a project must be stored in the internal memory, which can be expanded to 512MB with a DIMM. The built-in hard drive is only used for backing up projects.
