Roland JX-10

Analog Synthesizer Year: 1986

Description

The JX-10 is a 12-voice, digitally controlled analog synthesizer with 76 velocity-sensitive keys and channel aftertouch. Essentially a double JX-8P, it's 2-part multitimbral (Upper and Lower). Each voice features 2 DCOs (without pulse width modulation but with cross modulation), 1 resonant DCF, 1 dynamic DCA, 2 envelopes, and 1 LFO. The VCA can be switched to gate mode. It can operate on two independently selectable MIDI channels and can be programmed via the optional PG-800 programmer. The M-64C cartridge expands sound storage. A small, non-editable sequencer can record notes, program changes, hold, and portamento data to an M-16C or cartridge.

Features

  • 12-voice polyphony
  • 76 keys
  • 2 DCOs per voice
  • resonant filter
  • 2 envelopes
  • LFO
  • multitimbral
  • MIDI compatible
  • cartridge-based memory expansion
  • built-in sequencer
