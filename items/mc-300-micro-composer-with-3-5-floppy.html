MC-300 Micro Composer with 3.5" Floppy

Sequencer Year: 1988

Description

The MC-300 is a song-oriented MIDI sequencer with 2 independent MIDI outputs and a 3.5" floppy drive, whose operating system must be loaded from a floppy disk at startup. The hardware largely corresponds to the MC-500 but features small, flat buttons instead of large, high-travel buttons. The MC-300 was shipped with MRC-300 software, which turns it into a 4-track sequencer, capable of recording all 16 MIDI channels on each track. Additionally, a rhythm track is available, allowing up to 90 rhythm patterns with up to 32 different note numbers each to be arranged. These patterns can also be created by the user. The MC-300 can hold up to 8 songs in memory, provided there is enough space. Using the Microscope function, all entries (events) can be fully edited. Unfortunately, for various functions, the system diskette must be re-inserted repeatedly, which can be somewhat annoying. However, the MC-300 can also be started with other operating systems available for the MC-500 and MC-500MKII. With the S-MRC (Super-MRC) software, the MC-300 becomes an 8-track sequencer, also with a pattern-oriented rhythm track, where up to 240 patterns can be created instead of 90. The Performance-Package MRP-500 allows for creating stage-ready MRC-300 song sequences, complete with pauses (or not) and repetitions, which can be started with a simple button press. The Rhythm Bank MRD-500 provides pre-programmed patterns and software for arranging rhythm tracks, and the Bulk Librarian MRB-500 enables the management of bulk dumps from various – including non-Roland – devices. Furthermore, the MRM-500 software was available, allowing MRC-500 and S-MRC songs to be converted to Standard MIDI Files (SMF) and vice-versa. Unlike the MC-500, the MC-300's memory cannot be expanded and holds a maximum of 25,000 events. The MC-300 can be synchronized internally or externally via MIDI Clock signals, as well as via an FSK signal (Tape Sync) to tape machines.

Features

  • Song-oriented MIDI sequencer
  • 2 independent MIDI outputs
  • 3.5" floppy drive (OS loaded from diskette)
  • Hardware similar to MC-500, with flat buttons
  • Shipped with MRC-300 software (4-track sequencer, 16 MIDI channels per track)
  • Rhythm track: up to 90 user-creatable patterns (up to 32 different note numbers each)
  • Holds up to 8 songs in memory
  • Microscope function for full event editing
  • Compatible with MC-500/MC-500MKII operating systems
  • S-MRC (Super-MRC) software option: 8-track sequencer, up to 240 rhythm patterns
  • MRP-500 Performance-Package for stage-ready song sequences
  • MRD-500 Rhythm Bank for pre-programmed patterns and rhythm track arrangement
  • MRB-500 Bulk Librarian for managing bulk dumps (including non-Roland devices)
  • MRM-500 software for SMF conversion
  • Max memory: 25,000 events (not expandable)
  • Synchronization: internal, external MIDI Clock, FSK (Tape Sync)
  • Integrated power supply
  • Dimensions: 305 x 79.5 x 280 mm
  • Weight: 3.4 kg
