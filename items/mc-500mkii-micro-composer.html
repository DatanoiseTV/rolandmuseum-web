Roland MC-500MKII Micro Composer

MIDI Sequencer Year: 1988

Description

The MC-500MKII is a song-oriented MIDI sequencer with 2 independent MIDI outputs and a 3.5-inch floppy drive, requiring its operating system to be loaded from a disk at startup. The hardware, with its numeric keypad and overall design, strongly resembles a calculating machine and is equally excellent to operate. It features 6 drive buttons, 7 function buttons, 2 cursor buttons, an alpha-dial data entry wheel, 5 illuminated track buttons, and a non-backlit 2-line display for operation.

Features

  • Shipped with S-MRC software, enabling 8-track sequencing (16 MIDI channels per track)
  • Includes a tempo track and a rhythm track
  • Rhythm track supports up to 240 rhythm patterns, each with up to 32 different note numbers, user-creatable
  • Stores up to 8 songs, maximum 100,000 events
  • "Microscop" function for full editing of all events
  • Requires re-inserting the system diskette for various functions (can be annoying)
  • Compatible with other operating systems (e.g., Super-MRP Performance Package for stage-ready song sequences, MRD-500 Rhythm Bank for pre-programmed patterns, MRB-500 Bulk Librarian for managing bulk dumps)
  • MRM-500 software available for converting S-MRC songs to Standard MIDI Files (SMF) and vice versa
  • Synchronizable internally or externally via MIDI Clock signals and FSK (Tape Sync) to tape recorders
  • Dimensions: 305 x 91 x 285 mm
  • Weight: 3.4 kg
  • Power supply: Built-in power supply, Roland power cable
  • Included accessories: Roland 2-pole block power cable, S-MRC sequencer operating system
  • Recommended accessories: MRM-500 SMF-Converter software
