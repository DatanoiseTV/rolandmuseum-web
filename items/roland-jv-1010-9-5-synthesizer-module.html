Roland JV-1010 9.5" Synthesizer Module

Digital Synthesizer Year: 1999

Description

The JV-1010 is a 64-voice, 16-part multitimbral rack synthesizer module without a keyboard. Its sound library can be expanded using SR-JV80 series Wave Expansion Boards. It occupies 1U of half-rack width (9.5-inch) in a 19-inch format. It offers one insert multi-effect (MFX) alongside chorus and reverb, and features minimal control elements, requiring an editor program for detailed sound editing.

Features

  • 64-voice polyphony
  • 16-part multitimbral
  • Rack-mountable (1U, half-width 9.5-inch in a 19" format)
  • Expandable with SR-JV80 series Wave Expansion Boards
  • Effects: 1 Insert Multi-Effect (MFX), Chorus, Reverb
  • Requires editor software for full patch editing
  • Patches comprise up to 4 Tones, combinable via 10 structures
  • Each Tone includes: PCM oscillator, 12dB multi-mode filter, dynamic amplifier, 3 envelopes, 2 LFOs
  • Structures can add Booster and Ring Modulator; allows 24dB filter slopes with identical filter settings
  • Supports split, layer, and crossover sounds within a single patch (velocity and note range limits)
  • Includes ROM samples from JV-1080 and Session Board
  • Performances manage up to 15 parts (patches) and one rhythm set
  • Freely assignable MIDI channels per part
  • Dimensions: 218 x 45 x 237 mm
  • Weight: 1.4 kg
  • Includes ACI power adapter
