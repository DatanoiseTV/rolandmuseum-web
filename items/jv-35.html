Roland JV-35

Digital Synthesizer Year: 1993

Description

The JV-35 is a 28-voice, 16-part multitimbral, GS-compatible digital synthesizer with 61 velocity-sensitive keys. The sound generation is based on the Sound Canvas SC-55MKII module. Sounds cannot be fully programmed, but only modified in some parameters relative to the original. Such modified 'Tones' can be saved, as can 8 'Performances', which contain the complete settings for all parts. There is an expansion slot for a Voice Expansion Board, providing an additional 28 voices with either GS sounds or JV sounds.

Features

  • 28-voice polyphony
  • 16-part multitimbral
  • GS-compatible
  • 61 velocity-sensitive keys
  • Sound generation based on Sound Canvas SC-55MKII module
  • Limited sound programming (parameter modification relative to original)
  • Saveable 'Tones' and 8 'Performances' (full settings for all parts)
  • Expansion slot for Voice Expansion Board (adds 28 voices, GS or JV sounds)
  • Power supply: ACI adapter
