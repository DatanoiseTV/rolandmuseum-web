Roland SA-09 Saturn

Analog Synthesizer Year: 1980

Description

The Roland SA-09 Saturn is a 44-key analog organ. It allows users to blend four different footages of a basic tone using sliders. Four basic tones are selectable, ranging from sine wave to sawtooth wave. A monophonic VCO can be added for an additional 'attack' sound, reminiscent of early computer games. A 'sustain' (release) function can be toggled and its duration adjusted via a slider. A tone control slider and an effect unit switchable between chorus and vibrato complete the sound design options. The effects' modulation speed can be controlled, and they can be toggled between off, level I, and level II. A tuning control and an octave switch (-1 octave) finalize the controls.

Features

  • 44 keys
  • Analog Organ
  • 4 selectable basic tones
  • Monophonic VCO
  • Sustain (release) control
  • Chorus/Vibrato effects
  • Tuning control
  • Octave switch
