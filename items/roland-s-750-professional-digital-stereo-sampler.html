Roland S-750 Professional Digital Stereo Sampler

Sampler Year: 1991

Description

The Roland S-750 is a 24-voice, 16-bit stereo sampler with mouse and monitor connection. Sampling frequencies of 22.05, 44.1, or 48 kHz can be used. The S-750 must load its operating system at startup, either from a floppy disk or from SCSI-connected storage devices. The S-750 can be fully operated with its built-in display and buttons, though this is somewhat cumbersome. Alternatively, a monitor (or TV with S-Video input) and a mouse (MU-1), and optionally a remote control (RC-100), can be connected for a very comfortable user experience. The sound generation is structured as follows: A sample includes loop points and loop mode (forward, reverse, alternate, no loop), original pitch, and fine-tuning. Up to 4 samples can be assigned to a partial, which controls panorama, level, dynamic crossfading with fades, etc. Dynamic amplifiers, filters, envelopes, and LFOs are also part of the partial. Up to 88 partials can be distributed as non-overlapping zones across the note range (splits) to form a patch (sound program of a part). Up to 32 parts can be assigned MIDI channels and output routing to form a performance. For data storage, there is also the "Volume," which groups multiple performances and can be loaded into the S-750's memory at once. The factory memory is 2MB but can be expanded to a total of 18MB. This requires installing the RAS-750 memory expansion board, which then accepts OMS-750 memory modules. The S-750 is fully data-compatible with the S-770 and can also handle data from the S-760. One of these three samplers (S-750, S-770, or S-760) or the sample player SP-700 is referred to when speaking of the Roland S-700 series, for which there is a large library of samples from other manufacturers as well as from Roland itself.

Features

  • 24-voice polyphony
  • 16-bit stereo sampler
  • Mouse and monitor connection
  • Sampling frequencies: 22.05 kHz, 44.1 kHz, 48 kHz
  • Operating system loaded from floppy disk or SCSI devices
  • Built-in display and buttons for operation
  • External monitor (S-Video) and mouse (MU-1) support
  • Optional RC-100 remote control support
  • Sample parameters: loop points, loop modes (forward, reverse, alternate, no loop), original pitch, fine-tuning
  • Up to 4 samples per partial, controlling panorama, level, dynamic crossfading
  • Dynamic amplifiers, filters, envelopes, and LFOs per partial
  • Up to 88 partials as non-overlapping zones (splits) forming a patch
  • Up to 32 parts with MIDI channels and output assignments forming a performance
  • "Volume" for grouping and loading multiple performances
  • Factory memory: 2MB, expandable to 18MB with RAS-750 expansion board and OMS-750 modules
  • Data compatible with S-770 and S-760 samplers
  • Part of the Roland S-700 series with extensive sample library support
