Roland DMK-100

Generated Compact FX Year: 1982

Description

Delay Machine Kit (DMK-100) The delay device with good noise reduction and a long delay time of up to 300 ms. The separately usable outputs for effect and direct signal provide interesting sound results. DMK-100 technical data • Assembly process: 37 • Control: input level, Delay time, Intensity, Delay Vol. • Terminals: Input, Output (2 channels: D+E, E) • Input level: L: -50 dBm, M: 35 dBm, H: -15 dBm • Output level: H: -10 dBm, L: -25 dBm • Max. Output level: -3 dBm • Delaytime: 25 ms 300 ms • Dimensions: 210 (W) x 80 (H) x 166 (D) mm (8.27 x 3.15" x 6.54") • Weight: 1.750 g (3.75 Ibs.)
