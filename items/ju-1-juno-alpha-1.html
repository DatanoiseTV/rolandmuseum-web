Roland JU-1 JUNO-ALPHA-1

Analog Synthesizer Year: 1985

Description

The Alpha-Juno-1, also known as JU-1, is a 6-voice, digitally controlled analog synthesizer with 49 non-velocity-sensitive keys. However, the Alpha Juno can process MIDI velocity data and is compatible with (SysEx) data from Alpha-Juno-2, HS-10, HS-80, and MKS-50. For convenient parameter editing, the PG-300 programmer can be connected via MIDI. Each voice features a DCO, a fixed high-pass filter, a dynamic low-pass filter, a dynamic amplifier, an envelope generator, and an LFO. The sounds can then be thickened with a chorus effect. 64 unchangeable presets and 64 savable user sounds are available. The adjustable values are sometimes very coarsely stepped. The Alpha Juno-1 was also sold with a different color scheme as the HS-10 "Synth Plus 10" for home use.
