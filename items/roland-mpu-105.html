Roland Roland MPU-105

MIDI Management Year: 1985

Description

The MIDI Output Selector MPU-105 is a MIDI Thru box housed in a half-rack 19-inch enclosure. The MIDI IN signal can be routed to 5 MIDI THRU ports, each of which can be individually switched on or off. LEDs indicate power, incoming MIDI data, and which THRU ports are active. Unlike the MPU-104, this unit cannot be reversed in function or operated without an external power supply.

Features

  • MIDI Output Selector / MIDI Thru box
  • Half-rack 19-inch enclosure
  • Routes MIDI IN signal to 5 individually switchable MIDI THRU ports
  • Red LED for power supply indication
  • Green LED for incoming MIDI data indication
  • LEDs for active MIDI THRU ports (1 to 5)
  • Requires external PSA-series power adapter (not battery operable)
  • Cannot be reversed in function (unlike MPU-104)
  • Dimensions: 218 x 46 x 157 mm
  • Current consumption: 50mA
