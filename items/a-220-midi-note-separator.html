Roland A-220 MIDI Note Separator

MIDI Accessories Year: 1991

Description

The A-220 Note Separator is a 19" rack unit with one MIDI input and five MIDI outputs. One output is a THRU port, replicating the input signal. The other four outputs are divided into two pairs, A and B. Outputs A transmit all data not sent to outputs B. Outputs B can be assigned a single MIDI channel or specific MIDI note numbers, allowing incoming data to be split or separated between A and B.

Features

  • 1 MIDI input
  • 5 MIDI outputs (1 THRU, 2 pairs A and B)
  • Separates MIDI notes by channel or note number
  • 19" rack mountable
