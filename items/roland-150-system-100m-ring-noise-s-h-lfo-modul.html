Roland 150 System 100M, Ring, Noise, S&H, LFO Modul

Eurorack / Modular Year: 1979

Description

The Module 150 for the System-100M includes a Ring Modulator, Sample & Hold unit, and an LFO. The main function of the Ring Modulator is to combine two VCO outputs to create metallic-sounding tones. Sample & Hold: This random generator automatically produces tonal patterns according to the input waveform.

Features

  • Module for Roland System-100M
  • Ring Modulator
  • Sample & Hold (S&H) unit
  • Low-Frequency Oscillator (LFO)
  • Ring Modulator combines two VCO outputs for metallic tones
  • Sample & Hold generates random tonal patterns
  • Dimensions (W x H x D): 104 x 230 x 199 mm
  • Weight: 1.6 kg
  • Powered via 190, 191, or 191J modules
  • Recommended accessories: 190, 191, 191J Module Cases, 180, 181, 184 CV/Gate Keyboards, other modules (110 to 182)
