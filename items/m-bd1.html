Roland M-BD1

Sound Expansion Module Year: 1997

Description

The M-BD1 is an 8-part multitimbral sound module based on the JV-80's sound generation, featuring specialized waveforms exclusively for 'Bass & Drums'. These waveforms are identical to those found on the SR-JV80-10 Wave Expansion Board. It supports both Patch mode (single part active) and Performance mode (all eight parts active, with the eighth part for rhythm). MIDI channels are assignable per part. While it lacks user patches, its sound can be altered via SysEx data. Each patch comprises up to four Tones, each with a dynamic filter and amp, two LFOs, and three envelopes, with two Tones linked through 10 possible Structures.

Features

  • 8-part multitimbral sound module
  • Based on JV-80 sound engine
  • Specialized waveforms for 'Bass & Drums' sounds
  • Waveforms identical to SR-JV80-10 Wave Expansion Board
  • Patch mode (single part active) and Performance mode (8 parts active)
  • Eighth part in Performance mode dedicated to a rhythm set
  • Adjustable MIDI channel for each part
  • No user patches (sound modifiable via SysEx data)
  • Each patch consists of up to four Tones
  • Each Tone features a dynamic filter and amp, two LFOs, and three envelopes
  • Two Tones linked via 10 possible Structures
  • Dimensions: 482 (W) x 44 (H) x 165 (D) mm
  • Weight: 2.65 kg
  • Power consumption: 10W
  • Built-in power supply
