Boss DR-55 Dr.Rhythm

Drum Machine / Rhythm Year: 1979

Description

The Boss Dr.Rhythm DR-55 is a small, analog, and programmable rhythm machine designed for battery operation. It is notable as the first rhythm machine ever without preset rhythms. Users can program six patterns with 16 steps and two patterns with 12 steps (16th notes), each with a variation. Instruments such as bass drum (BD), snare (SN), rimshot, and accent are all programmable. A slide switch allows the Hi-Hat to be set to off, 8th notes, or 16th notes. Another slide switch determines whether only variation A, only variation B, or both are played alternately. Dedicated controls are available for adjusting volume, tempo, tone, and accent strength. Rhythm patterns are selected using a large rotary switch. Start and stop functions are handled by buttons, or via an external footswitch connected to the FOOT SW jack. On the left side, there's a mono output and two synchronization jacks: DBS provides a pulse with each step, and CSQ with each programmed accent (pulses approximately 4 to 5 volts). The DR-55 cannot be operated as a slave device and lacks a dedicated power supply input.

Features

  • Analog and programmable rhythm machine
  • Battery-powered (4 x 1.5V AA/LR6 mignon batteries)
  • First rhythm machine without preset rhythms
  • Six 16-step patterns and two 12-step patterns, each with a variation
  • Programmable instruments: Bass Drum, Snare, Rimshot, Accent
  • Hi-Hat settings: Off, 8th notes, 16th notes via slide switch
  • Slide switch for selecting Variation A, Variation B, or alternating playback
  • Controls for volume, tempo, tone, and accent strength
  • Large rotary switch for rhythm pattern selection
  • Start/Stop buttons, Footswitch input (FOOT SW)
  • Mono output
  • Synchronization jacks: DBS (pulse per step), CSQ (pulse per accent)
  • Cannot be operated as a slave
  • No external power supply input
  • Dimensions: 211 x 53 x 116 mm
  • Weight: 0.85 kg
