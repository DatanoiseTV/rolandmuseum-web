Boss TU-120

Guitar/Bass FX Year: 1979

Description

The TU-120 is a chromatic tuner with a rotary switch for the 12 basic notes and an LED chain to display tuning accuracy. The display range is C2 to B6, with A4 adjustable to 440, 442, 443, or 444 Hz. The LEDs act as an interference running light; the brightest point indicates correct tuning. A microphone for tuning acoustic instruments is included. Calibration is required before tuning, using the FUNCTION switch and CALIBRATION knob.

Features

  • Chromatic Tuner
  • Rotary Switch for 12 Notes
  • LED Tuning Display
  • A4 Tuning Adjustment (440-444 Hz)
  • Built-in Microphone
  • Calibration Function
