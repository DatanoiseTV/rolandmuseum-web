Roland S-550

Samplers Year: 1987

Description

The S-550 is a 16-voice rack-mount digital sampler with a 3.5" floppy drive for sample storage. It's the rack version of the S-50 keyboard sampler, offering double the memory and dynamic filters. It can store a maximum of 4 x 7.2 seconds of samples, divided into 2 blocks with 2 banks (A and B) each. The S-550 samples at 12-bit resolution with selectable 15 or 30kHz sampling rates, but sounds very good thanks to its excellent 16-bit converters. Sounds are created by combining up to 64 raw samples with playback parameters, forming "Tones". Tones can be assigned to keys and saved as Patches (up to 32). The single-line display is not ideal for editing, so a monitor, mouse, and even a drawing tablet (DT-100) can be connected. The operating system loads from disk. The optional HD5-IF SCSI interface allows connection of an Apple-compatible hard drive (up to 80MB) or the CD-5 CD-ROM drive. The SYS-553 DIRECTOR-S software (hardware dongle protected) turns the S-550 into a multi-track MIDI sequencer.

Features

  • 16-voice digital sampler
  • 3.5" floppy drive
  • 4 x 7.2 seconds sample memory
  • 12-bit sampling, 15/30kHz
  • Dynamic filters
  • SCSI interface optional (HD5-IF)
  • Monitor, mouse, and tablet support
