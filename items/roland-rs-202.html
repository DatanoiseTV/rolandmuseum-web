Roland RS-202

Analog Synthesizer Year: 1976

Description

The Roland RS-202 String Ensemble is a polyphonic analog keyboard with 61 non-velocity-sensitive keys designed for creating string sounds. Housed in a hard case with a removable lid, it offers two keyboard zones, each with independent on/off control for its three sounds (brass and two string variations). The brass and string sounds can be individually adjusted, and a fixed-frequency vibrato with adjustable intensity is available for the entire keyboard. Each zone also has a switch for slightly dampening volume and toggling attack time between slow and fast. The RS-202 adds an ensemble switch (off, I, and II), providing a Roland chorus effect, and a delayed vibrato compared to its predecessor, the RS-101. It lacks a headphone output, offering two line outputs carrying the same mono signal at different levels.

Features

  • Polyphonic analog keyboard
  • 61 non-velocity-sensitive keys
  • String and brass sounds
  • Two keyboard zones
  • Adjustable vibrato
  • Ensemble (chorus) effect
  • Slow/fast attack time switch
  • Line outputs (high/low levels)
