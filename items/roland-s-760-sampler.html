Roland S-760 Sampler

Sampler Year: 1994

Description

The Roland S-760 is a 24-voice, 16-bit stereo sampler in a 1U rack format with a built-in display. Sampling frequencies of 22.05, 44.1, or 48 kHz can be used. The S-760 requires its operating system to be loaded at startup, either from a system floppy disk or from data storage devices connected to the SCSI port. While the S-760 can be operated entirely using its built-in display and buttons, this is very cumbersome. For this purpose, the optional OP-760-1 expansion board was available, allowing connection of a monitor (or TV with S-video input), a MU-1 mouse, and optionally an RC-100 remote control for comfortable operation. This board also expanded the 4 analog outputs with 2 digital stereo outputs (S/P-DIF), which could be converted back to analog signals with the optional DA-400. Sound generation is structured as follows: A sample contains loop points and loop mode (forward, reverse, alternating, no loop), original pitch, and fine-tuning. Up to 4 samples can be assigned to a Partial, which controls panorama, level, dynamic crossfading with fades, etc. Dynamic amplifiers, filters, envelopes, and LFOs are also part of the Partial. Up to 88 Partials can be distributed as non-overlapping zones across the note range (splits) to form a Patch (sound program of a Part). A maximum of 32 Parts, each with MIDI channels and output assignments, can form a Performance. For data storage, there is also the 'Volume' concept, which groups multiple Performances and can be loaded into the S-760's memory at once. The factory memory is 2MB, but can be expanded to a total of 32MB with SIM72-8 or SIM72-16. The S-760 is data-compatible with the S-750 and S-770 (as well as the SP700 Sample Player).

Features

  • 24-voice, 16-bit stereo sampler
  • 1U rack format with built-in display
  • Sampling frequencies: 22.05, 44.1, 48 kHz
  • Operating system loaded from system floppy or SCSI-connected devices
  • Optional OP-760-1 expansion board for monitor (S-video), MU-1 mouse, and RC-100 remote control
  • OP-760-1 board adds 2 digital stereo outputs (S/P-DIF) to 4 analog outputs
  • Digital outputs convertible to analog with optional DA-400
  • Sample parameters include loop points, loop mode (forward, reverse, alternating, no loop), original pitch, fine-tuning
  • Up to 4 samples per Partial, controlling panorama, level, dynamic crossfading
  • Partials include dynamic amplifiers, filters, envelopes, and LFOs
  • Up to 88 Partials can form non-overlapping zones (splits) for a Patch (sound program)
  • Up to 32 Parts with MIDI channels and output assignments form a Performance
  • 'Volume' concept for grouping and loading multiple Performances
  • Factory memory: 2MB, expandable to 32MB with SIM72-8 or SIM72-16
  • Data compatible with S-750, S-770, and SP700
  • Integrated power supply, IEC power cable
  • Dimensions: 482 x 44 x 362.3 mm
  • Weight: 4.2 kg
