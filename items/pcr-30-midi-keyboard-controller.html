Edirol PCR-30 MIDI Keyboard Controller

MIDI Keyboard Controller Year: 2002

Description

The PCR-30 is a velocity-sensitive keyboard with 32 standard-sized keys and offers 8 rotary knobs, 8 faders, and 9 freely programmable buttons. It can send not only MIDI Control Change information but also MIDI SysEx data, MIDI Clock, RPN, and NPRN information. The Bender/Lever for pitch bend and modulation operates linearly, and for convenient use with a computer, the PCR-30 is equipped with a USB connection and a MIDI interface (MIDI In and Out). There are connections for a sustain pedal and an expression pedal, and settings can be stored in 15 memory locations.

Features

  • 32 velocity-sensitive full-sized keys
  • 8 freely programmable rotary knobs
  • 8 freely programmable faders
  • 9 freely programmable buttons
  • MIDI Control Change support
  • MIDI SysEx data support
  • MIDI Clock support
  • RPN and NPRN information support
  • Linear Pitch Bend/Modulation lever
  • USB connection
  • MIDI In/Out interface
  • Sustain pedal input
  • Expression pedal input
  • 15 user memory locations for settings
  • Includes AC power adapter
  • Includes CD-ROM
  • Includes USB cable
