PW-10 V-Wah

Guitar/Bass FX Year: 2002

Description

The Wah Pedal for the 21st Century! This revolutionary, programmable modeling wah gives you immediate access to six characteristic classic and modern wah pedal sounds. Additionally, the legendary Uni-Vibe effect is included, as well as the completely new "Double Resonance" and "Voice" sounds that have never before been available in a wah pedal! Furthermore, the V-Wah offers eight simulations of legendary distortion pedals, three memory slots for custom sounds, and wear-free, noiseless infrared operation.

Features

  • COSM Modeling Wah Pedal
  • Six Classic and Modern Wah Models (CBY-Wah, VO-Wah, MO-Wah, Advanced, Bass, Custom)
  • Uni-Vibe Effect with Pedal Control
  • Eight Overdrive/Distortion Types (e.g., OD-1, OD-2, MT-2, DS-1, BD-2, Muff Fuzz, Guv Dist, Booster)
  • New 'Voice' Mode for Talking Vocal Sounds
  • New 'Double Resonance' Mode for Analog Synth-like Sounds
  • Three Memory Slots for Custom Settings
  • Wear-free and Noiseless Infrared Pedal Mechanism
  • Wah Range Control for Filter Adjustment
  • Digital Memory
