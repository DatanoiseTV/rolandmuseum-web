Roland S-50 MIDI Sampler

Sampler Year: 1986

Description

The S-50 is a 16-voice digital sampler with a velocity-sensitive 61-key keyboard and a 3.5-inch floppy drive for sample storage. It is Roland's first sampler to feature memory for 2 x 7.2 seconds of samples and can sample at 15 or 30kHz. The memory cannot be expanded. Despite the 12-bit resolution, the S-50 sounds surprisingly good thanks to its excellent 16-bit converters. The sound basis consists of a maximum of 32 pure samples, which are assigned playback parameters to become "Tones." Tones can be freely distributed across the keyboard and stored as a Patch (sound program). The S-50 allows for creating 8 Patches. Unlike its successors, the S-50 has no dynamic filters. The single-line display is not inviting for editing; however, a monitor, mouse, and a tablet for drawing waveforms (DT-100) can be connected. The operating system must be loaded from a floppy disk at startup. With the optional, hardware-dongle-protected DIRECTOR-S software SYS-503, the S-50 can transform into a multi-track MIDI sequencer.

Features

  • 16-voice digital sampler
  • 61-key velocity-sensitive keyboard
  • 3.5-inch floppy drive for sample storage
  • Sample memory for 2 x 7.2 seconds (unexpandable)
  • Sampling rates: 15 kHz or 30 kHz
  • 12-bit sample resolution with 16-bit D/A converters
  • Max 32 samples per patch
  • 8 patch memory slots
  • No dynamic filters
  • Connections for external monitor, mouse, and DT-100 graphics tablet
  • Operating system loaded from floppy disk at startup
  • Optional multi-track MIDI sequencer functionality with DIRECTOR-S software (SYS-503)
  • Integrated power supply
  • Dimensions: 1105 x 93 x 328 mm
  • Weight: 13 kg
