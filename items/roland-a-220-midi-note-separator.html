Roland A-220 MIDI Note Separator

Utility Year: 1991

Description

The A-220 Note Separator is a 19-inch rack unit with one MIDI input and 5 MIDI outputs. One output is a THRU jack, which re-transmits the signal received via MIDI IN without alteration. The other 4 outputs are divided into 2 pairs of jacks, A and B. Outputs A output all data not output by outputs B. A single MIDI channel or specific MIDI note numbers can be assigned to B, so that incoming data at IN is split, or separated, between A and B.

Features

  • 19-inch rack unit (1U)
  • 1 MIDI Input
  • 5 MIDI Outputs
  • 1 MIDI THRU output
  • 4 dedicated MIDI outputs for data separation (2 pairs A and B)
  • Splits incoming MIDI data based on MIDI channel or specific note numbers
  • Built-in power supply
