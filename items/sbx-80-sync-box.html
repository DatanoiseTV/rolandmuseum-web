SBX-80 Sync-Box

Utility Year: 1984

Description

The SBX-80 is a Sync Box used for common tempo control of connected MIDI devices (MIDI Clock), DIN-Sync devices, and those requiring trigger impulses, supporting 1, 2, 3, 4, 12, 24, 28, or 96 impulses per quarter note. The tempo of the SBX-80 can be entered in Manual mode via a rotary knob or tapped in via the TAP button. Additionally, up to 8 tempo sequences for songs can be programmed. In Slave mode, only the programmed songs can be run, with SMPTE or MIDI Clock selectable as synchronization sources. The SBX-80 can also generate SMPTE code. Real-time conversion from DIN-Sync or trigger to MIDI Clock, etc., is not possible, especially since there is no DIN Sync input.

Features

  • Sync Box for tempo control
  • Supports MIDI Clock, DIN-Sync, and Trigger impulses
  • Trigger impulses supported: 1, 2, 3, 4, 12, 24, 28, or 96 per quarter note
  • Manual tempo input via rotary knob
  • TAP tempo button
  • Up to 8 programmable tempo sequences for songs
  • Slave mode with SMPTE or MIDI Clock sync sources
  • Can generate SMPTE code
  • No real-time conversion from DIN-Sync/trigger to MIDI Clock
  • No DIN Sync input
