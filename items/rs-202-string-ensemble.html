RS-202 String Ensemble

Analog Synthesizer Year: 1976

Description

The Roland Strings RS-202 is a polyphonic, analog keyboard with 61 non-velocity-sensitive keys for generating string imitations. The RS-202 is firmly built into an instrument case, from which the lid can be removed. The RS-202 has two keyboard zones for which the total of 3 sounds can be switched on and off independently. The Brass sound and the two String sounds can be separately adjusted in tone, and a fixed-frequency vibrato's intensity can be controlled for the entire keyboard. For each keyboard zone, the volume can be slightly attenuated with a rocker switch, and the attack time can be switched between Slow and Fast. A master volume control is available. Compared to its predecessor, the RS-101, the ability to delay vibrato and, primarily, the 3-position Ensemble switch (Bypass, I, and II) have been added. This is the typical Roland chorus effect. There is no headphone output, but only two line outputs that carry the same mono signal at higher and lower levels.

Features

  • Polyphonic analog keyboard
  • 61 non-velocity-sensitive keys
  • Built-in instrument case with removable lid
  • Two keyboard zones
  • 3 independent sounds: Brass, String 1, String 2
  • Individual tone control for Brass and String sounds
  • Fixed-frequency vibrato with intensity control
  • Volume attenuation and attack time (Slow/Fast) per zone
  • Master volume control
  • 3-position Ensemble switch (Bypass, I, II) for Roland chorus effect
  • Two mono line outputs (high/low level)
  • No headphone output
  • Internal power supply with fixed power cable
  • Dimensions: 910 x 163 x 360 mm
  • Weight: 17 kg
  • Sales period: 1976-1979
