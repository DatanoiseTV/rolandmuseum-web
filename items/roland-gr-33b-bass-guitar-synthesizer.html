Roland GR-33B BASS GUITAR SYNTHESIZER

Analog Synthesizer Year: 1982

Description

The GR-33B Bass Guitar Synthesizer is a 4-voice polyphonic instrument, designed to complement the nature of a bass guitar and offers capabilities comparable to the GR-300 guitar synthesizer. It features extensive control over pitch, LFO, two envelope generators, a switchable VCF, and VCA modulation, specifically tailored for bass guitar signals.

Features

  • 4-voice polyphonic analog synthesizer
  • VCOs: Master Tune, Pitch A/B (±1300 cents), Pitch Latch/Unlatch switches
  • LFO: Rate (2-10Hz), Delay (0-4 sec)
  • VCF: Filter Mode A (-24dB/oct), Filter Mode B (-12dB/oct), ENV Modulation
  • ENV GEN: Two blocks (A/B) with Attack (0-3 sec) and Decay (0-10 sec) times
  • Footswitches: Pitch A, Pitch B, VCF MOD, ENV A/B, VCA MOD
  • String Select: 4-way switch with indicators for individual string activation/deactivation
  • External Foot Control inputs for VCF Pedal and String Select
  • Input: 24-PIN Connector
  • Outputs: Mix/Synthesizer, Guitar
  • Dimensions: 400(W) x 100(H) x 290(D) mm
  • Weight: 5 kg (11 lbs.)
