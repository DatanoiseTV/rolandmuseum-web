Roland GK-KIT-BG

Pickup Installation Kit Year: 2007

Description

The Roland GK-KIT-BG is an installation kit for a hexaphonic pickup that can be installed in a bass guitar using routing and soldering to control 13-pin bass synthesizers or virtual bass systems. The pickup should be mounted about 10mm behind the bridge and connected with a short cable to the control electronics, which must be built into the bass body. The two buttons "S1" and "S2", the switch from BASS to MIX to only GK, as well as the 13-pin socket for connecting the GK cable should be accessible through drilled holes. This installation kit does not provide MIDI signals itself, as is sometimes incorrectly assumed, but is a prerequisite for a 13-pin device (e.g., V-Bass, GR-20, GI-20, VB-99, etc.) to generate MIDI signals from it.

Features

  • Hexaphonic pickup
  • 13-pin connection
  • S1/S2 switches
  • Bass/Mix/GK switch
