Roland RS-101

String Ensemble, Keyboard Synthesizer Year: 1975

Description

The Roland Strings RS-101 is a polyphonic, analog keyboard with 61 non-velocity-sensitive keys for generating string imitations. The RS-101 is permanently built into its instrument case, with a removable lid. It features two keyboard zones, for which the total of 3 sounds (!) can be independently switched on and off. The brass sound and the two string sounds can be separately adjusted in tone, and a fixed-frequency vibrato intensity can be controlled for the entire keyboard. For each keyboard zone, volume can be slightly attenuated with a rocker switch, and attack time can be switched between slow and fast. A master volume knob is present. There are no further sound design settings. There is no headphone output, only two line outputs that carry the same mono signal at higher and lower levels. Unlike other string ensembles from this era, the RS-101 has independent envelopes for individual voices.

Features

  • Polyphonic, analog keyboard
  • 61 non-velocity-sensitive keys
  • String imitations
  • Built into an instrument case with removable lid
  • Two keyboard zones
  • 3 sounds (Brass, 2x String)
  • Independent tone control for sounds
  • Fixed-frequency vibrato with intensity control
  • Volume attenuation per zone (rocker switch)
  • Switchable attack time (Slow/Fast) per zone
  • Master volume control
  • Two mono line outputs (high/low level)
  • Independent envelopes for individual voices
