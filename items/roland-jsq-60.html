Roland JSQ-60

Sequencer Year: 1983

Description

The JSQ-60 is a 1-track sequencer for the Juno-60 or Jupiter-8 with a DCB connection, capable of recording approximately 2000 notes (8kByte memory). It records note numbers and note lengths, program changes for the Juno-60, and patch selections for the Jupiter-8. Recording can be done in real-time or step-by-step, and overdubs are possible. The memory content is retained for approximately 24 hours but can be saved to tape (Tape Save/Load). Two DIN-Sync jacks are available for synchronizing external devices. The JSQ-60 operates only as a master. The DCB cable is fixed and only 1m long, so the synthesizer to be controlled must be nearby.

Features

  • 1-track sequencer
  • DCB (Digital Control Bus) connection
  • Compatible with Roland Juno-60 and Jupiter-8
  • Approx. 2000 note capacity (8KB memory)
  • Records note numbers, note lengths, program changes (Juno-60), and patch selections (Jupiter-8)
  • Real-time and step recording
  • Overdub capabilities
  • Memory retention for approx. 24 hours
  • Tape Save/Load function
  • 2 DIN-Sync jacks for external synchronization (master only)
  • Fixed 1m DCB cable
