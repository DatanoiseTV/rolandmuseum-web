Roland MC-50MKII 8-Track Super MRC MIDI Sequencer

Sequencer Year: 1993

Description

The MC-50MKII is a compact, song-oriented MIDI sequencer with 2 independent MIDI outputs, a 3.5" floppy drive, and a backlit display. Unlike its predecessors MC-500 (MKII), the main operating system does not need to be loaded from a floppy disk; the 8-track S-MRC sequencer, the Super-MRP Performance Package program, and the SMF converter software MRM-500 are already integrated, making the MC-50MKII immediately ready for use. However, the MC-50MKII can also be fed with alternative operating systems like MRB-500 (Bulk Librarian) from a floppy disk. In normal operation, the MC-50MKII is an 8-track sequencer, with all 16 MIDI channels recordable on each track. In addition to a tempo track, a rhythm track is available, on which up to 240 rhythm patterns with up to 32 different note numbers each can be arranged. These patterns can also be created by the user. The MC-50MKII can hold up to 8 songs in memory, provided the memory space, approximately 40,000 events, is sufficient. All entries (events) can be fully edited using the Microscop function. The MC-50MKII can be synchronized internally or externally via MIDI Clock signals, as well as via an FSK signal (Tape Sync) to tape recorders. The MC-50MKII needs to convert floppy disks and songs from its predecessors MC-500, MC-300, and MC-500MKII and cannot play them directly. Reverse conversion of MC-50MKII songs to MC-300/500(MKII) songs is not possible.

Features

  • Compact, song-oriented MIDI sequencer
  • 2 independent MIDI outputs
  • 3.5" floppy drive
  • Backlit display
  • Integrated 8-track S-MRC sequencer
  • Integrated Super-MRP Performance Package program
  • Integrated SMF converter software (MRM-500)
  • Supports alternative operating systems like MRB-500 (Bulk Librarian) via floppy
  • Each track supports 16 MIDI channels
  • Tempo track
  • Rhythm track for up to 240 patterns, each with up to 32 different note numbers
  • Up to 8 songs in memory (approx. 40,000 events)
  • Microscop function for full event editing
  • Synchronizable via internal clock, external MIDI Clock, or FSK (Tape Sync)
  • Requires conversion of songs from MC-500, MC-300, and MC-500MKII (no direct playback)
  • No reverse conversion from MC-50MKII songs to older formats
