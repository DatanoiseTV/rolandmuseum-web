Roland A-880

MIDI Patchbay Year: 1988

Description

A 19" MIDI patchbay for 8 INs and 8 OUTs. MIDI IN1 can be merged with another input. The patchbay offers 64 memories for assignments. The patchbay allows distributing a total of 8 MIDI inputs to 8 MIDI outputs, where one input can indeed be routed to multiple outputs. Conversely, outputs cannot receive signals from multiple inputs. An exception is any output to which the signal from channel 1 can be additionally mixed using the merge function. The A-880 patchbay has no display, only illuminated buttons, which makes programming and overview of the set assignments difficult. Without a manual, one will hardly be able to master this patchbay satisfactorily.

Features

  • 19-inch rack-mountable MIDI patchbay
  • 8 MIDI inputs and 8 MIDI outputs
  • MIDI IN1 can be merged with another input
  • 64 memory locations for routing assignments
  • One input can be routed to multiple outputs
  • Outputs cannot receive signals from multiple inputs (with one exception for merging)
  • Merge function allows adding MIDI IN1 to any output
  • No display, only illuminated buttons
  • Integrated power supply
