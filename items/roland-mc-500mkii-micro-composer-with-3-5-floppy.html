Roland MC-500MKII Micro Composer with 3.5" Floppy

Sequencer Year: 1988

Description

The MC-500MKII is a song-oriented MIDI sequencer with 2 independent MIDI outputs and a 3.5" floppy drive, whose operating system must be loaded from a floppy disk at startup. The hardware, with its numeric keypad and design, resembles a calculating machine and offers excellent operability. It features 6 drive buttons, 7 function buttons, 2 cursor buttons, an Alpha-Dial for value input, 5 illuminated track buttons, and an unfortunately non-backlit 2-line display. The MC-500MKII was delivered with the S-MRC software, enabling it to function as an 8-track sequencer, where all 16 MIDI channels can be recorded on each track. A tempo track and a rhythm track are also available, allowing up to 240 rhythm patterns, each with up to 32 different note numbers, to be arranged. Users can create their own patterns. The MC-500MKII can store up to 8 songs in memory, provided the maximum memory space of 100,000 events is sufficient. All entries (events) can be fully edited using the Microscop function. Unfortunately, constantly inserting the system floppy for various functions can be annoying. The MC-500MKII can also be started with other operating systems, such as the Performance Package Super-MRP for creating stage-ready song sequences, the Rhythm Bank MRD-500 for pre-programmed patterns, or the Bulk Librarian MRB-500 for managing bulk dumps. Since the S-MRC software does not natively support Standard MIDI Files (SMF), the MRM-500 software was available for converting S-MRC songs to SMFs and vice versa. The MC-500MKII differs from its predecessor mainly by its larger memory. Songs and operating systems can be loaded alternately from MC-500 and MKII. It synchronizes internally or externally via MIDI Clock or FSK (Tape Sync) signals.

Features

  • Song-oriented MIDI sequencer
  • 2 independent MIDI outputs
  • 3.5" floppy drive for OS and data
  • 8-track sequencer (with S-MRC software), each track supporting 16 MIDI channels
  • Tempo track
  • Rhythm track for up to 240 patterns, each with up to 32 different note numbers
  • Up to 8 songs in memory (max 100,000 events)
  • Microscop function for full event editing
  • Compatible with various operating systems (S-MRC, Super-MRP, MRD-500, MRB-500, MRM-500)
  • Synchronizable via internal clock, external MIDI Clock, or FSK (Tape Sync)
  • Non-backlit 2-line display
  • Numeric keypad, Alpha-Dial, function and cursor buttons
