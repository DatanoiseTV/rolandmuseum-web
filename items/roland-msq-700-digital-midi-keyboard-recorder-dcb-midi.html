Roland MSQ-700 Digital MIDI-Keyboard Recorder (DCB & MIDI)

Sequencer Year: 1984

Description

The MSQ-700 is an 8-track MIDI sequencer, capable of recording data from all 16 MIDI channels on each track. Notes can be recorded via real-time input or step-by-step entry, and overdubs are possible (e.g., to record data from other MIDI channels in subsequent passes). The MSQ-700 is song-oriented, meaning it does not feature patterns (reusable song sections). The MSQ-700 lacks detailed editing functions, but multiple tracks can be merged into one (Merge function), and the playback order of tracks can be determined using the Chain function. In total, approximately 6500 events can be recorded, making the MSQ-700 the 'big brother' of the MSQ-100 and a successor to the CSQ-600. The MSQ-700 can operate as a master or slave, via MIDI or DIN SYNC, as well as to an FSK signal, which the MSQ-700 can also generate. Data can be saved to tape/cassette recorder (using an FSK signal, which can nowadays also be recorded with an HD recorder).

Features

  • 8-track MIDI sequencer
  • Records data from all 16 MIDI channels per track
  • Real-time recording
  • Step-by-step entry
  • Overdubbing capability
  • Song-oriented (no patterns)
  • Merge function (combines multiple tracks)
  • Chain function (determines track playback order)
  • Approximately 6500 events storage
  • Master or slave operation via MIDI, DIN SYNC, or FSK signal
  • Generates FSK signal
  • Data storage to tape/cassette recorder via FSK
  • Dimensions: 346 x 108 x 328 mm
  • Weight: 5 kg
