Roland Roland MKS-70 MIDI Synth Modul SUPER JX

Synthesizer Module Year: 1986

Description

The SUPER JX MKS-70 is a 12-voice, MIDI-controlled, analog synthesizer module in a 19-inch rack format with 2 rack units. Each voice features two digitally controlled oscillators (DCOs), a non-dynamic high-pass filter, a dynamic 24dB low-pass filter, an LFO, and two envelope generators. Both DCOs produce sawtooth, square/pulse waves (with variable pulse width) and noise, and can be tuned in semitone steps across footages from 16 feet to 2 feet, detuned against each other, and hard-synced. A special feature allows the pitch spread of one oscillator to be set below 100%. The low-pass filter is resonant, and the envelopes respond to both velocity and keyboard position (key follow). At first glance, the MKS-70 appears very similar to the MKS-80, but sounds completely different, partly due to the very coarse stepping of adjustable parameter values. The MKS-70 lacks the bite and punch of the MKS-80, but excels at smooth, lush pad sounds. The MKS-70 is the rack version of the JX-10. An individual sound program is called a 'Tone,' with 50 preset Tones and 50 additional user Tones savable internally. The MKS-70 is 2-part multitimbral, allowing two Tones to be combined as Split or Dual. A combination is called a 'Patch,' which stores the octave range, bend behavior, playing mode (Solo, Unison, Polyphonic) of the Tones, and their volume balance. 64 internal patch memories are available. An external M-64C memory cartridge can be inserted to double the available memory. Furthermore, the MKS-70 can be edited via MIDI SysEx commands, though a complete dump is not possible. Since creating sounds on the MKS-70 via parameter number selection and subsequent value input by button is cumbersome, the PG-800 programmer, also designed for JX-8P and JX-10, can be connected, which has dedicated controls for all relevant parameters.

Features

  • 12-voice polyphony
  • MIDI-controlled
  • Analog synthesizer module
  • 19-inch rack format, 2U
  • Per voice: two DCOs, non-dynamic high-pass filter, dynamic 24dB low-pass filter, LFO, two envelope generators
  • DCOs with sawtooth, square/pulse waves (variable pulse width) and noise
  • DCOs tunable from 16 feet to 2 feet footage
  • Detuning and hard sync capabilities
  • Adjustable pitch spread for one oscillator
  • Resonant low-pass filter
  • Envelopes respond to velocity and key follow
  • Rack version of JX-10
  • 50 preset Tones, 50 user Tones internally savable
  • 2-part multitimbral (Split, Dual modes)
  • 64 internal patch memories
  • M-64C memory cartridge for external storage
  • MIDI SysEx editing (no complete dump)
  • Compatible with PG-800 programmer
  • Dimensions: 482 x 88 x 400 mm
  • Weight: 7.6 kg
