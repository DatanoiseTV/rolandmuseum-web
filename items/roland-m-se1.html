Roland Roland M-SE1

Sound Module Year: 1995

Description

The Roland M-SE1 is an 8-part multitimbral sound module specialized for string ensembles and solo strings. Based on the JV-80's sound engine, it contains only specific string waveforms. The M-SE1 can trigger unique string effects through legato playing not possible with other JV synthesizers. Therefore, the M-SE1's sounds are not available as an expansion board. Operable in Patch or Performance mode, it allows individual MIDI channel settings for each part. While lacking user patches, the sounds can be modified via SysEx data. A patch consists of up to four tones, each with a dynamic filter and amp, two LFOs, and three envelopes, where two tones are linked via ten structures.

Features

  • 8-part multitimbral sound module
  • Specialized string sounds
  • Legato-triggered string effects
  • Patch and Performance modes
  • SysEx sound editing
  • Based on JV-80 sound engine
