Roland S-760 Sampler

Sampler Year: 1994

Description

The Roland S-760 is a 24-voice, 16-bit stereo sampler in a 1U rack-mount format with a display. Sampling frequencies of 22.05, 44.1, or 48kHz can be used. The S-760 requires its operating system to be loaded at startup, which can be done from a system floppy disk or from data carriers connected via the SCSI port. The S-760 can be fully operated using its built-in display and buttons, though this is quite cumbersome. For more convenient operation, the optional OP-760-1 expansion board allowed for the connection of a monitor (or TV with S-Video input), a MU-1 mouse, and optionally a remote control (RC-100). This board also expanded the 4 analog outputs with 2 digital stereo outputs (S/P-DIF), which could then be converted back to analog signals using the optional DA-400. Sound generation is structured around samples, partials, patches, and performances for complex sound design. The factory memory is 2MB, but can be expanded to a total of 32MB with SIM72-8 or SIM72-16 modules. The S-760 is data compatible with the S-750 and S-770.

Features

  • 24-voice polyphony
  • 16-bit stereo sampler
  • 1U rack-mount format with integrated display
  • Selectable sampling frequencies: 22.05, 44.1, 48 kHz
  • Operating system loaded at startup (from floppy or SCSI)
  • SCSI port for external storage
  • Optional OP-760-1 expansion board for external monitor (S-Video), MU-1 mouse, and RC-100 remote control
  • 4 analog outputs
  • 2 digital stereo outputs (S/P-DIF) with optional OP-760-1 board
  • Sample structure with loop points and modes (forward, reverse, alternate, no loop), original pitch, and fine-tuning
  • Partial structure with up to 4 samples, panorama, level, dynamic crossfading, amplifiers, filters, envelopes, and LFOs
  • Patch structure combining up to 88 Partials (splits)
  • Performance structure combining up to 32 Parts with MIDI channels and output assignment
  • Volume concept for grouping and loading multiple Performances
  • Factory memory: 2MB, expandable to 32MB with SIM72-8/SIM72-16 RAM
  • Data compatible with S-750, S-770, SP700
  • Built-in power supply
