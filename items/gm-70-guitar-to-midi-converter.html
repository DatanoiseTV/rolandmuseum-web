Roland GM-70 Guitar-to-MIDI-Converter

Guitar-to-MIDI Converter Year: 1986

Description

The Roland GM-70 is a Guitar-To-MIDI converter for G-guitars with a 24-pin connection (e.g., G-202, G-303, G-505, G-707, G-808, or a guitar with GK-1) housed in a 19-inch 1U rackmount chassis. It converts signals from a hexaphonic pickup into MIDI notes and other associated MIDI performance data, without its own sound generation. The GM-70 features 128 program memories for storing various settings as 'patches'. Each patch contains settings for up to four 'branches', designed for controlling four different MIDI sound modules.

Features

  • Each branch allows setting MIDI base channel, pitch bending strength, dynamics curve, level, program number, and MIDI mode (monophonic or polyphonic)
  • Controller assignments to MIDI control commands are stored in a patch
  • Rear connections for two buttons, an expression pedal, and an RRC jack for the FC-100 pedalboard, each assignable to a function
  • Patch settings can be output via MIDI Bulk Dump as SysEx data, saved on an external sequencer, and reloaded
  • Built-in tuner with adjustable reference pitch (430 Hz to 450 Hz in 0.1 Hz steps)
  • MIDI IN primarily responds to program change data
  • Allows routing external MIDI module audio through STEREO IN/OUT for GM-70 controlled volume, also mixing in the normal guitar signal to STEREO OUT (if GUITAR OUT is not used)
  • Reliable, albeit somewhat slow, guitar signal conversion
  • Dimensions: 482 x 44 x 276 mm
  • Weight: 4 kg
  • Power supply: Built-in power supply, fixed power cable
  • Included accessories: PJ-1 audio cable, 2 x 2.5m MCS MIDI cable
  • Recommended accessories: FC-100 RRC Foot Controller, EV-5 Expression Pedal, DP-2 Footswitch (Sustain Pedal), G-guitar with 24-pin connector
