Roland JUNO-106

Synthesizer Year: 1984

Description

The Juno-106 is a 6-voice analog synthesizer with 61 keys. Each voice features an oscillator (DCO), high-pass filter, dynamic low-pass filter, dynamic amplifier, and an envelope generator. Sound generation is similar to its predecessor, the Juno-60. The Juno-106 has more patch memory than the Juno-60 (128 vs. 56), organized into two groups of eight banks with eight patches each. Patches can be saved to and loaded from cassette tape. The Juno-106 has a MIDI interface and transmits both notes and parameter values via SysEx, allowing patch changes to be sent to a second Juno-106 or a sequencer.

Features

  • 6-voice analog synthesizer
  • 61 keys
  • DCO, high-pass filter, dynamic low-pass filter, dynamic amp
  • 128 patch memory
  • MIDI interface
  • SysEx data transmission
