Roland RS-505 String Paraphonic 505

Keyboard Synthesizer Year: 1978

Description

The RS-505, named 'Paraphonic 505' on the housing, is an analog 49-key keyboard with 3 sound generation sections and two keyboard zones, Upper and Lower, with a fixed split point at middle C. The Bass section consists of a monophonic synthesizer with 3 sounds (Contra Bass 16, Tuba 8, and Cello 8) switchable via rocker switch and an adjustable AR envelope. The volume can be adjusted via a slider, and the Ensemble effect, common to all sections, can be switched on. The polyphonic 'Synthesizer' section also has fixed registers (Bass 16, Bass 8, Lower 8, Lower 4, Upper 8, and Upper 4), but offers a filter with adjustable cutoff frequency and resonance, which can be modulated by an LFO or an ADSR envelope. Unfortunately, the RS-505 has only a single envelope generator for all voices, so the envelope is only triggered when all keys have been released previously. The Ensemble effect can be switched on for the entire Synthesizer section. The volume of the Synthesizer section can be set as a balance to the String section for both the Upper and Lower parts. The polyphonic String section offers a slider per zone (Upper/Lower) for adjusting the mix ratio of 8' and 4' strings and a rocker switch for turning the respective zone on/off. For the strings, in addition to the switchable Ensemble effect, there is an Attack control, which, similar to the Synthesizer section, only comes into play with staccato playing. Therefore, one should actually say for both the String and Synthesizer sections that they do not operate polyphonically but homophonically. Furthermore, there is an LFO adjustable in rate and delay, an adjustable Vibrato, the switch for the Ensemble effect (I, II, or off), an adjustable Autobend function or manual pitch lowering by up to an octave, and controls for overall tuning and volume. On the rear, the RS-505 has the following outputs: Stereo Output, Synth Bass Output (takes Bass and Synthesizer Bass sounds out of the Stereo Output when connected), Trigger and Gate Output. Ext IN (audio input located before the Ensemble effect), Pitch (switches transposition on/off), Sustain (hold function), and VCF (control input for pedal) are the available inputs.

Features

  • Analog 49-key keyboard.
  • 3 sound generation sections.
  • Two keyboard zones: Upper and Lower, with fixed split point at middle C.
  • Bass section: monophonic synthesizer with 3 switchable sounds (Contra Bass 16, Tuba 8, Cello 8) and adjustable AR envelope.
  • Synthesizer section: fixed registers (Bass 16, Bass 8, Lower 8, Lower 4, Upper 8, Upper 4), filter with adjustable cutoff and resonance, LFO/ADSR modulation.
  • Single envelope generator for all voices (homophonic operation).
  • String section: per zone (Upper/Lower) slider for 8'/4' string mix, on/off switch.
  • Shared Ensemble effect (switchable I, II, or off).
  • Adjustable Attack control for strings and synthesizer (for staccato playing).
  • LFO adjustable in rate and delay.
  • Adjustable Vibrato.
  • Adjustable Autobend function or manual pitch lowering (up to an octave).
  • Controls for overall tuning and volume.
  • Outputs: Stereo, Synth Bass, Trigger, Gate.
  • Inputs: Ext IN (audio), Pitch (transpose on/off), Sustain, VCF (pedal control).
  • Dimensions (WxDxH): 905 x 145 x 370 mm.
  • Weight: 14 kg.
  • Built-in power supply.
  • Included accessories: DP-1 footswitch (sustain pedal), PJ-1 audio cable (2 x 2.5m).
