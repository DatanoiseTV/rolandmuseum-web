Roland PK-5 MIDI Bass Pedal

Synthesizer Addons Year: 1990

Description

A MIDI foot keyboard with 13 pedals that usually send notes in the bass range on MIDI channel 2 after power-on. Various buttons allow you to change the octave, MIDI channel, or note arrangement for E-series arrangers. You can also set whether only the last pressed note is output or if the pedal works polyphonically. The hold button keeps the notes sounding after releasing the pedals. It's velocity-sensitive but can be switched to fixed velocity 64. You can use the MIDI PRG button and pedals to set a program change number sent when you press the 'H' pedal. Buttons activate controller values: CC93=On, CC93=Off, CC92=On, CC92=Off, CC07=0,30, 45, 64, 80, 95 or 110, and CC64=On/Off. The Factory Set button lets you send sequencer functions (Start, Stop, and E-Series control functions) using the pedals.

Features

  • 13 pedals
  • MIDI foot keyboard
  • Velocity sensitive (switchable to fixed velocity 64)
  • Polyphonic operation
  • Hold button
  • MIDI PRG function
  • Controller value assignment
  • Sequencer control functions
