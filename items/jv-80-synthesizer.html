JV-80 Synthesizer

Digital Synthesizer Year: 1992

Description

The JV-80 is a 28-voice, 8-part multitimbral digital synthesizer featuring 61 velocity-sensitive keys with aftertouch. A sound program (Patch) can consist of up to 4 Tones, which can be combined using one of 10 structures. Each Tone includes a PCM oscillator, a 12dB multi-mode filter, a dynamic amplifier, 3 envelopes, and 2 LFOs. Structures allow for optional boosters and ring modulators, and a 24dB filter slope can be achieved with identical filter settings. It supports split, layer, and crossover sounds within a single patch, and Performances manage up to 7 Parts and one Rhythm Set. The sound library is expandable via Wave Expansion Boards, making it the first in the JV/XP series based on its 4-Tone, 10-structure sound generation.

Features

  • 28-voice polyphony
  • 8-part multitimbral
  • 61 velocity-sensitive keys with aftertouch
  • Sound program (Patch) consists of up to 4 Tones
  • 10 structures for combining Tones
  • Each Tone includes: PCM oscillator, 12dB multi-mode filter, dynamic amplifier, 3 envelopes, 2 LFOs
  • Optional boosters and ring modulators via structure selection
  • Can achieve 24dB filter slope with identical filter settings
  • Split, layer, and crossover sounds possible within a patch
  • Performance mode manages up to 7 Parts and 1 Rhythm Set
  • Expandable sound library via Wave Expansion Board for additional PCM samples
  • First synthesizer in the JV/XP series
  • Built-in power supply, Roland power cable
  • Dimensions: 990 (W) x 85 (H) x 305 (D) mm
  • Weight: 9 kg
  • Power consumption: 15W
