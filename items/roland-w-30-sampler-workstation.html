Roland W-30 Sampler Workstation

Sampler Year: 1989

Description

The W-30 'Music Workstation' is a 16-voice digital sampler with a velocity-sensitive 61-key keyboard, a 3.5-inch floppy drive for sample storage, and a built-in sequencer comparable to the MC-500. The sample memory, offering 2 x 7.2 seconds at 30kHz or 2 x 14.4 seconds at 15kHz samples, is not expandable. The 12-bit resolution inherited from the S-50 is compensated by very good 16-bit converters, resulting in a relatively good sound for the W-30. The sound basis consists of a maximum of 32 pure samples, which are combined with playback parameters to form 'Tones.' Tones can be freely distributed across the keyboard and saved as Patches (sound programs). The W-30 allows for creating 16 Patches. Like the S-330 and S-550, the W-30 has dynamic filters. The sequencer features a tempo track and 16 MIDI tracks, with each track able to record data on all 16 MIDI channels. The W-30 can read song data from Director S sequencers of other S-samplers, MC-500, and Super-MRC. Operation is performed via various buttons and a combination of cursor wheel and value wheel. Visual feedback is provided by an 8-line liquid crystal display with waveform representation. However, operation is not as comfortable as with other samplers where a mouse and monitor can be connected. Data storage uses the built-in 3.5-inch floppy drive or an external hard drive (SCSI, max 80MB!), provided the KW-30 SCSI interface is installed and a functional hard drive is connected. As with all other S-samplers, the operating system must first be loaded from a data medium after power-on.

Features

  • 16-voice digital sampler
  • Velocity-sensitive 61-key keyboard
  • Built-in 3.5-inch floppy drive for sample storage
  • Integrated sequencer (comparable to MC-500)
  • Sample memory: 2 x 7.2 seconds at 30kHz or 2 x 14.4 seconds at 15kHz
  • 12-bit resolution processed by 16-bit converters
  • Up to 32 pure samples as sound basis (Tones)
  • 16 savable Patches
  • Dynamic filters
  • Sequencer with tempo track
  • 16 MIDI tracks, each recording on all 16 MIDI channels
  • Reads song data from Director S sequencers, MC-500, and Super-MRC
  • Operation via buttons, cursor wheel, and value wheel
  • 8-line liquid crystal display with waveform representation
  • Data storage on internal floppy or external SCSI hard drive (max 80MB with KW-30 interface)
  • Operating system loaded from media at power-on
  • Dimensions: 1014(W) x 106(H) x 301(D) mm
  • Weight: 9.8 kg
  • Built-in power supply with Roland power cable
  • Included accessories: SYS-W30-6 System Diskette, X6-W30-01/02/03 Data Disks
