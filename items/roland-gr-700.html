Roland GR-700

Guitar/Bass FX Year: 1984

Description

The GR-700 is a 6-voice analog guitar synthesizer with a 24-pin connection and MIDI output. It uses guitars from the GR series (G-202, G-303, G-505, G-707, G-808, or guitars with a GK-1 pickup). The sound generation is based on the JX-3P, but it's velocity-sensitive. It features two digitally controlled oscillators (DCOs) per string, a DCF filter, and a DCA amplifier. It can store 64 patches internally and another 64 on an optional M-16C memory cartridge. It also functions as a guitar-to-MIDI interface, though with noticeable latency.

Features

  • 6-voice analog guitar synthesizer
  • 24-pin connection
  • MIDI output
  • 11 footswitches
  • Two 7-segment displays
  • 64 internal patches
  • Optional memory cartridge for 64 additional patches
  • Guitar-to-MIDI interface
