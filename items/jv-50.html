Roland JV-50

Digital Synthesizer Year: 1993

Description

The JV-50 is a 28-voice, 16-part multitimbral, GS-compatible digital synthesizer with 61 velocity-sensitive keys and a sequencer for SMF files. The sound generation is based on the SoundCanvas SC-55MKII module. Sounds cannot be fully programmed but can only be altered in some parameters relative to the original. Such modified 'Tones' can be saved, as can 8 Performances, which contain the complete settings for all parts. The JV-50 is identical to the JV-35 except for the sequencer and also has an expansion slot for a Voice Expansion Board, which provides an additional 28 voices with either GS or JV sounds.

Features

  • 28-voice polyphony
  • 16-part multitimbral
  • GS-compatible digital synthesizer
  • 61 velocity-sensitive keys
  • Sequencer for SMF files
  • Sound generation based on SoundCanvas SC-55MKII module
  • Sounds not fully programmable, but adjustable relative to original
  • Storage for modified 'Tones' and 8 Performances
  • Expansion slot for Voice Expansion Board
  • Voice Expansion Board provides an additional 28 voices (GS or JV sounds)
  • Production period: 1993-1995
  • Dimensions (W x H x D): 1011 x 92 x 289 mm
  • Weight: 6.6 kg
  • Power supply: 1.2A AC adapter
  • Included accessories: ACB power supply, PJ-1M audio cable, DD floppy disk storage
  • Recommended accessories: VE-GS1, VE-JV1 Voice Expansion Boards, DP-2 foot switch (sustain pedal), DD floppy disk storage
