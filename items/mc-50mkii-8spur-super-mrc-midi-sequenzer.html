Roland MC-50MKII 8Spur Super MRC MIDI Sequenzer

MIDI Sequencer Year: 1993

Description

The MC-50MKII is a compact, song-oriented MIDI sequencer with 2 independent MIDI outputs, a 3.5" floppy drive, and a backlit display. Unlike its predecessors MC-500 (MKII), the main operating system does not need to be loaded from a floppy disk; the 8-track S-MRC sequencer, the Super-MRP Performance Package program, and the SMF converter software MRM-500 are already integrated, making the MC-50MKII ready for immediate use. However, the MC-50MKII can also be fed with alternative operating systems like MRB-500 (Bulk Librarian) from floppy disk. In normal operation, the MC-50MKII is an 8-track sequencer, capable of recording all 16 MIDI channels on each track. Additionally, a rhythm track is available alongside the tempo track, on which up to 240 rhythm patterns, each with up to 32 different note numbers, can be arranged. These patterns can also be created by the user. The MC-50MKII can hold a maximum of 8 songs in memory, provided the memory space, approximately 40,000 events, is sufficient. All entries (events) can be fully edited using the Microscope function. The MC-50MKII can be synchronized internally or externally via MIDI Clock signals, as well as via an FSK signal (Tape Sync) to tape machines. The MC-50MKII requires conversion of floppy disks and songs from its predecessors MC-500, MC-300, and MC-500MKII and cannot play them directly. Reconversion of MC-50MKII songs into MC-300/500(MKII) songs is not possible.

Features

  • Compact, song-oriented MIDI sequencer
  • 2 independent MIDI outputs
  • 3.5" floppy drive
  • Backlit display
  • Integrated operating system (no floppy loading at startup)
  • Integrated 8-track S-MRC sequencer
  • Integrated Super-MRP Performance Package
  • Integrated SMF converter software MRM-500
  • Supports alternative operating systems (e.g., MRB-500 Bulk Librarian)
  • 8 tracks for recording (all 16 MIDI channels per track)
  • Rhythm track for up to 240 patterns (each with up to 32 note numbers)
  • User-creatable rhythm patterns
  • Maximum of 8 songs in memory (approx. 40,000 events)
  • 'Microscope' function for full event editing
  • Internal or external synchronization (MIDI Clock, FSK Tape Sync)
  • Requires conversion for songs/disks from predecessors (MC-500, MC-300, MC-500MKII)
  • No reconversion from MC-50MKII format to older formats
