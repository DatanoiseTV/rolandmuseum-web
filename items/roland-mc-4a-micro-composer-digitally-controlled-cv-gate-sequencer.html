Roland MC-4A Micro-Composer, Digitally Controlled CV/Gate Sequencer

Sequencer Year: 1981

Description

The MC-4 is a digital sequencer for CV/Gate signals, featuring 4 independent tracks. Sequences can be programmed step-by-step, played in using a CV/Gate keyboard, or entered using a two-stage process (first pitches, then step length). All entries can be edited directly on the MC-4, though users need to adapt to its specific 15-character display.

Features

  • Dimensions: 471 x 124 x 348 mm
  • Weight: 6.3 kg
  • Built-in power supply (30W) with fixed power cable
  • 4 independent tracks for CV/Gate signals
  • Step-by-step programming
  • Real-time input via CV/Gate keyboard
  • Two-stage input method (pitch then step length)
  • Onboard editing with a 15-character display
  • Per track: two control voltages (CV-1, CV-2), Gate, and an MPX trigger signal (e.g., for portamento)
  • Built-in DIN-SYNC (master/slave) for synchronization with compatible devices (e.g., CSQ-600, CR-8000, TB-303, MC-202, TR-606, TR-808)
  • TAPE SYNC connections for FSK signal recording to tape for synchronization
  • External CV input for tempo control
  • Functions for saving, loading, and verifying data on external audio recorders (tape/cassette)
  • MC-4A model: 16kB internal memory (approx. 3700 notes/events)
  • MC-4B model: 48kB internal memory (approx. 11500 notes/events) with MTR-100 data cassette recorder interface
  • MC-4A upgradable to full MC-4B functionality via OM-4 retrofit kit
