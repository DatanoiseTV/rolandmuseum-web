Roland MC-8 Micro Composer

Sequencer Year: 1977

Description

The Roland MC-8 MicroComposer is a computer-controlled 8-channel CV/Gate sequencer and the first fully editable sequencer. It comprises two hardware components: the control computer with input buttons and the connection panel, linked by a multi-pin cable. Each channel offers CV and Gate signals, plus six MPX outputs for triggering various functions. Sequences can be entered via CV/Gate input from an external keyboard or the numeric keypad. The MC-8 uses a tape interface for sequence storage. The FSK signal can be recorded using a cassette recorder or HD recorder. External synchronization is possible via FSK.

Features

  • 8-channel CV/Gate sequencer
  • First fully editable sequencer
  • Two hardware components
  • CV/Gate and MPX outputs
  • Tape interface for storage
  • FSK synchronization
