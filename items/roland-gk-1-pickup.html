Roland Roland GK-1 Pickup

Guitar Synthesizer Controller Year: 1986

Description

The Roland GK-1 is a hexaphonic pickup with a 24-pin connector for mounting on standard guitars to control 24-pin system guitar synthesizers. Unlike normal pickups, the hexaphonic pickup captures each string individually, providing six separate signals. The GK-1 is essentially two-part, consisting of the pickup itself, which should be mounted approximately 10mm behind the bridge, and a control box connected via a short cable. The control box, which is fixed with a special bracket on the strap button and on the guitar surface, has a jack input to connect the signal of the normal pickups, so that this is also transmitted via the 24-pin cable. The four controls on the control box are for overall volume, the ratio of normal pickup to synthesizer signal, and 2 control signals. The 24-pin cable is permanently connected to the control box.

Features

  • Hexaphonic pickup (captures each string individually)
  • 24-pin connector
  • Mounts on standard guitars
  • Separate control box
  • Four controls: Overall volume, normal pickup/synth signal ratio, 2 control signals
  • Jack input for normal guitar pickups
  • 24-pin cable permanently connected to the control box
  • Dimensions: 68 x 27 x 113.5 mm
  • Weight: 0.428 kg
