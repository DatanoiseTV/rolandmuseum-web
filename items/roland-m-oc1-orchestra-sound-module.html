Roland Roland M-OC1 Orchestra Sound Module

Sound Module Year: 1995

Description

The M-OC1 is an 8-part multitimbral sound module for orchestral sounds, based on the sound generation of the JV-80 but containing only special waveforms identical to those of the SR-JV80-02 Wave Expansion Board. The M-OC1 can operate in either patch mode or performance mode. In Patch Mode only one part is active, in Performance Mode all eight, the eighth part being intended for a rhythm set. The MIDI channel can be set for each part. The M-OC1 doesn't have any USER Patches, but its sound can be modified using SysEx data. A patch consists of up to four tones, each with a dynamic filter and amplifier, two LFOs, and three envelopes, with 2 tones each linked by 10 possible structures.

Features

  • 8-part multitimbral sound module
  • JV-80 based sound engine
  • Orchestral sounds
  • Patch and performance modes
  • SysEx data support
