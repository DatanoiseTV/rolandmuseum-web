Roland PR-100 MIDI Sequencer

Sequencer Year: 1987

Description

The PR-100 is a simple MIDI sequencer with a 2.8" drive, 2 tracks, and 2 so-called subtracks that separately contain the last recording on a main track. In addition, there is a rhythm track on which rhythm data from pre-assigned QDs can be muted separately. Using the merge function and the two main tracks, a complex song can be gradually assembled using the overdub method. The 2.8" QuickDisk drive built into the PR-100, which served to save and load data, was an attempt at the time to introduce a new data storage format in music electronics, but it did not catch on. Unfortunately, these QD drives are also extremely prone to failure, and only a few are still functional today. The PR-100 can store approximately 17,000 events internally and approximately 8,500 per side of a QD. For the PR-100 and the MT-100 (equipped with an additional sound module), an extensive library of QuickDisks with piano pieces for practice was optionally available.

Features

  • MIDI Sequencer
  • 2.8" QuickDisk drive for data storage
  • 2 main tracks
  • 2 subtracks (contain last recording on a main track)
  • Rhythm track with mute function for pre-assigned QDs
  • Merge function for overdubbing
  • Internal storage: approx. 17,000 events
  • QD storage: approx. 8,500 events per side
  • Dimensions: 305 x 58 x 199 mm
  • Weight: 1.5 kg
  • Power supply: 1.2A AC adapter (included)
  • Included accessories: AC adapter, 2 QuickDisks, 2 MSC MIDI cables
  • Optional accessories: DP-2 foot switch (sustain pedal), FS-5U foot switch
