DB-770 Digital Booster

Utility Year: 1993

Description

The DB-770 is a 9.5-inch device that has a coaxial S/P-DIF input and output, between which a digital audio signal can be boosted by +3, +6, or +x dB. The DB-770 has no other functions.

Features

  • 9.5-inch rackmount device
  • Coaxial S/P-DIF input
  • Coaxial S/P-DIF output
  • Digital audio signal boost options: +3dB, +6dB, or variable (+x dB)
