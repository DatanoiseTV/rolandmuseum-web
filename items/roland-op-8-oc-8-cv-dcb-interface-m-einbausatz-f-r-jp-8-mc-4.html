Roland Roland OP-8/OC-8 CV/DCB Interface m. Einbausatz für JP-8/MC-4

CV/DCB Interface Year: 1982

Description

The Roland OP-8 is an interface with CV/Gate inputs and DCB output, forming the link between analog sequencers like the MC-4A or MC-8 and DCB-controllable synthesizers such as the JUNO-60 and JUPITER-8. Early units of these synthesizers did not have a DCB interface but could be retrofitted with the OC-8 kit. In Germany, the OP-8 was sold together with the OC-8. The OP-8 features one CV and one Gate input (implemented as mini-jacks) for 8 voices, divided into 2 blocks of four, 'Upper' and 'Lower'. Additionally, each block has a CV input for VCF and VCA control. For signal distribution, there is a 4-fold patch field with 3 jacks each. A transpose switch allows shifting the octave range by +/- 1 octave, and two controls determine the range of VCF and VCA control. Under 'Patch Select', there is also an MPX and CV input, allowing for switching Jupiter-8 patches.

Features

  • CV/Gate inputs
  • DCB output
  • Connects analog sequencers (e.g., MC-4A, MC-8) to DCB-controllable synthesizers (e.g., JUNO-60, JUPITER-8)
  • OC-8 retrofit kit for DCB functionality
  • 8 CV and 8 Gate inputs (mini-jacks), divided into Upper and Lower blocks
  • CV input for VCF control per block
  • CV input for VCA control per block
  • 4-fold patch field with 3 jacks each for signal distribution
  • Transpose switch for +/- 1 octave range shift
  • Two controls for VCF and VCA control range
  • MPX and CV input for Patch Select (Jupiter-8)
