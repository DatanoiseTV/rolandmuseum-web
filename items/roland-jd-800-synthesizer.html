Roland JD-800 Synthesizer

Digital Synthesizer Year: 1991

Description

The JD-800 is a 24-voice digital synthesizer with 61 velocity-sensitive keys, as well as 59 sliders and 3 rotary controls for sound editing. It can operate in either Single Mode or as a 6-part multitimbral sound generator (5 normal + 1 Drum Part). For the PCM sound source, 108 waveforms are selectable, which pass through a digital, dynamic filter and then a dynamic amp. Additional waveforms can be loaded via a card slot. A sound program consists of 4 such 'Tones', whose levels can be mixed. Effects include Chorus, Delay, and Reverb; in Single Mode, several multi-effect types are also available. 64 patches, 16 performances (called Multi-Setup here), and 1 User Drum Set can be stored internally, as well as on an inserted RAM card.

Features

  • 24-voice polyphony
  • Digital synthesizer
  • 61 velocity-sensitive keys
  • 59 sliders and 3 rotary controls for sound editing
  • Single Mode and 6-part multitimbral operation (5 normal + 1 Drum Part)
  • PCM sound source with 108 selectable waveforms
  • Digital, dynamic filter
  • Dynamic amplifier
  • Card slot for loading additional waveforms (SO-PCM1 series compatible)
  • Sound programs composed of 4 'Tones' with mixable levels
  • Built-in effects: Chorus, Delay, Reverb, and multi-effect types in Single Mode
  • Internal storage for 64 patches, 16 performances, 1 User Drum Set
  • RAM card support for additional storage (M-512E, M-256E compatible)
  • Integrated power supply
  • Dimensions: 1040 x 108 x 420 mm
  • Weight: 15 kg
