Roland PR-1G 2-Track Sequencer

Sequencer Year: 1992

Description

The PR-1G is a simple 2-track MIDI sequencer without editing functions but with an integrated library of piano pieces for practicing. The PR-1G differs from the PR-1 only in the selection of integrated pieces, with the G version (G for German) containing German titles. For own recordings, storage space of approx. 4000 events is available. Only 1 own song can be recorded, and data backup is not provided. However, data is retained after switching off (provided the buffer battery still has power). A metronome can be switched on with time signatures of 1-4 half notes, 1 to 8 quarter notes, or 1 to 9 eighth notes, and the tempo can be set from 10 to 250 BPM.

Features

  • 2-track MIDI sequencer
  • No editing functions
  • Integrated library of piano practice pieces (German titles in G version)
  • Storage for approx. 4000 events
  • Records only 1 user song
  • No data backup function
  • Data retained after power off (with buffer battery)
  • Metronome with adjustable time signatures (1-4 half, 1-8 quarter, 1-9 eighth notes)
  • Adjustable tempo: 10 to 250 BPM
  • Power: 9V Block battery (6LR61) or PSA AC adapter
  • Current draw: 40mA
  • Dimensions: 174 x 65 x 142 mm
