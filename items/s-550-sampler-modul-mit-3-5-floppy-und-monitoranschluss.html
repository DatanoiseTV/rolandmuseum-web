Roland S-550 Sampler-Modul mit 3,5" Floppy und Monitoranschluss

Digital Sampler Module Year: 1987

Description

The S-550 is a 16-voice digital sampler module in a 2U rack format with a 3.5-inch floppy drive for sample storage. It is Roland's rack version of the S-50 keyboard sampler and offers twice the memory and dynamic filters. The memory holds a maximum of 4 x 7.2 seconds of samples, divided into 2 blocks with 2 banks each (A and B). The S-550 samples at 12 bits with selectable rates of 15 or 30kHz, but sounds excellent thanks to its superb 16-bit converters. The sound basis consists of a maximum of 64 pure samples, which are assigned playback parameters to become 'Tones'. Tones can be freely distributed across the keyboard and stored as a Patch (sound program). The S-550 allows 32 patches to be created. The single-line display is not inviting for editing; instead, a monitor and mouse, as well as a tablet for drawing waveforms (DT-100), can be connected. The operating system must be loaded from a floppy disk at startup. With the HD5-IF, a SCSI connection can be retrofitted to the S-550, to which a maximum 80MB (yes, megabytes!) Apple-compatible SCSI hard drive or the CD-5 CD-ROM drive can be connected. Using the optional, hardware-dongle-protected DIRECTOR-S software SYS-553, the S-550 can transform into a multi-track MIDI sequencer.

Features

  • 16-voice digital sampler module
  • 2U rack format
  • 3.5-inch floppy drive for sample storage
  • Double memory compared to S-50 keyboard sampler
  • Dynamic filters
  • Max 4 x 7.2 seconds of samples (in 2 blocks, 2 banks each)
  • 12-bit sampling at 15 or 30kHz
  • High-quality 16-bit converters
  • Monitor and mouse connectivity
  • Operating system loaded from floppy disk
  • Optional SCSI interface (HD5-IF) for up to 80MB SCSI hard drive or CD-5 CD-ROM drive
  • Optional multi-track MIDI sequencer functionality with DIRECTOR-S software (SYS-553)
  • 32 patch storage locations
