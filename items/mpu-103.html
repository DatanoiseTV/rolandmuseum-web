Roland MPU-103

MIDI Channel Filter/Converter Year: 1985

Description

The MPU-103 is a MIDI channel filter and converter in a 1/2 19" housing with MIDI IN, OUT, and THRU connectors on the rear. The signal arriving at MIDI IN is output unchanged at THRU. At MIDI OUT, data from a freely selected MIDI channel (using the FILTER rotary switch) is output, where the channel number can either be retained or set to any other number using the CONVERTER rotary switch. A red LED indicates power supply (via PSA series AC adapter), and a green LED indicates the arrival of MIDI data. The MPU-103 was originally intended to be named MI-30 but was only released under the MPU-103 designation.

Features

  • MIDI channel filter functionality
  • MIDI channel converter functionality
  • 1/2 19" rack-mountable housing (with optional RAD-10 rack adapter)
  • MIDI IN, OUT, and THRU ports
  • THRU port outputs unchanged MIDI IN data
  • FILTER rotary switch for selecting MIDI channel for output
  • CONVERTER rotary switch for reassigning MIDI channel number
  • Power indicator LED (red)
  • MIDI data activity indicator LED (green)
  • Powered by BOSS PSA-series AC adapter
  • Originally planned as MI-30
