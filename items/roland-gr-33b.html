Roland GR-33B

Guitar/Bass FX Year: 1982

Description

The GR-33B bass guitar synthesizer is designed to be 4-voice polyphonic and is in no way inferior to the GR-300 guitar synthesizer. Master Tune The master tuning control is used to tune the pitch between the synthesizer and the guitar. Pitch A/B Are additionally pre-programmed transposed tunings that can be played alone or in DUET with the basic tuning. Duet The "DUET" foot switch adds a chorus effect to Pitch A or B and significantly enhances the fullness of the sound. Latch/Unlatch The "Latch" switch position means constant activation of the transposed tuning, while "Unlatch" only switches the desired tuning when the "Pitch" switch is pressed down. String Select Starting from the fundamental tone, you can use "Pitch" to change the tunings by plus/minus one octave. When changing the tuning to a pitch that is far below the fundamental tuning, there is a risk that the low frequencies will no longer be reproduced correctly by the speakers. It is possible to switch off the low strings E4 and A3 using the "String Select circuit". Of course, this is also possible for special sounds with each individual string. LFO Rate and LFO Delay The LFO in the GR-33 B has a tempo control "RATE" and a "DELAY" with an adjustable time delay of up to four seconds. With this time-delaying circuit, for example, cello sounds etc. can be produced. ENV GEN The GR-33 B has two preset envelopes (ENV GEN A and ENV GEN B) that can be activated optionally. The control options are: ENV GEN Attack The time after the string is struck until the maximum volume and ENV GEN Decay, the decay time to the average volume. Both envelopes can in turn control the (! the) filter VCF. VCF The strength of the filter influence is determined by the ENV MOD control. The (incorrect! The) filter itself can be switched from -12 dB to -24 dB. VCA MOD By activating the VCA MOD switch, the VCA in the GR-33 B is controlled by the selected envelope, in order to create, for example, strongly swelling sounds (bowed double bass). Connections MIX: Mono output for bass and synthesizer GUITAR: Bass guitar output SYNTH: Synthesizer output VCF PEDAL: Connection possibility for a pedal for foot control of the CUTTOF FREQ (e.g. Roland FV-100) STRING SELECT: Connection possibility of a foot switch for the STRING SELECT ON / OFF section (e.g. ROLAND FS-1) GR-77B SPECIFICATIONS • VCO (4-VCO): Master Tune: Pitch A (±1300 cent), Pitch B (±1300 cent), Pitch LATCH/ UNLATCH Switch (2), LFO: LFO Rate (2 to 10Hz), LFO Delay (0 to 4 sec) • VCF: Filter Mode A (24dB/oct.), Filter Mode B (-12dB/ oct.), ENV Modulation • ENV GEN: A Block: Attack Time (0 to 3 sec), Decay Time (0 to 10 sec), B Block: Attack Time (0 to 3 sec), Decay Time (0 to 10 sec) • Foot Switch: Pitch A, Pitch B, VCF MOD, ENV A/B, VCA MOD • String Select: String Select Switch (4), Indicator (4) • Ext. Foot Control: VCF Pedal, String Select • Input: 24-PIN Connector • Output: Mix/ Synth., Guitar • Dimensions: 400(W) x 100(H) x 290(D) (15.7" x 3.9" x 11.4") • Weight: 5kg (11 Ibs.)

Features

  • 4-voice polyphonic
  • master tuning control
  • pitch A/B transposed tunings
  • duet chorus effect
  • latch/unlatch switch
  • string select
  • LFO rate and delay
  • two preset envelopes (ENV GEN A and B)
  • VCF filter
  • VCA MOD
  • pedal connections for VCF and string select
