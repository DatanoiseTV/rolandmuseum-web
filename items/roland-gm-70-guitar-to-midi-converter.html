Roland GM-70 Guitar-to-MIDI-Converter

Utility Year: 1986

Description

The Roland GM-70 is a Guitar-to-MIDI converter for G-Guitars with a 24-pin connector (G-202, G-303, G-505, G-707, G-808, or guitar with GK-1) in a 19" rack-mount chassis (1U). It converts signals from the hexaphonic pickup into MIDI notes and other associated MIDI performance data and has no internal sound generation. The GM-70 has 128 program memories where various settings can be stored as a 'patch'. A patch includes settings for up to four 'branches', which are intended for controlling four different MIDI sound generators. For each branch, you can set the MIDI base channel, pitch bending intensity, a dynamic curve, level, a program number, and the MIDI mode (monophonic, where each string sends on its own MIDI channel, or polyphonic). The assignments of various controllers to MIDI control commands are also stored in a patch. In addition to the pickup's controls, the GM-70 has rear-panel connections for two buttons and an expression pedal, as well as an RRC jack for the FC-100 pedalboard, which can each be assigned a function. GM-70 patch settings can be output via Bulk Dump over MIDI as SysEx data, saved on an external sequencer, and reloaded via MIDI IN if needed. The GM-70 has a built-in tuner, whose concert pitch can be set in 0.1 Hz steps from 430 Hz to 450 Hz. Otherwise, MIDI IN only responds to program change data. If connected MIDI sound generators cannot respond to CC#7 data (volume), their audio outputs can be connected to the STEREO IN jacks on the rear and then picked up again from the STEREO OUT jacks, where the GM-70 controls the output volume. The normal guitar signal is also mixed into STEREO OUT, unless the GUITAR OUT jack is used, where the original signal from the normal guitar pickups can be accessed. The GM-70 converts guitar signals very reliably, albeit quite slowly.

Features

  • Guitar-to-MIDI converter
  • For G-Guitars with 24-pin connector
  • 19" rack-mount chassis (1U)
  • Converts hexaphonic pickup signals into MIDI notes
  • No internal sound generation
  • 128 program memories (patches)
  • Four 'branches' for controlling MIDI sound generators
  • Adjustable MIDI base channel, pitch-bending, dynamic curve, level, program number, MIDI mode (monophonic/polyphonic)

  • MIDI IN responds to program change data
  • STEREO IN / STEREO OUT jacks
  • GUITAR OUT jack
