Roland MV-8000 Production Studio

Groovebox Year: 2003

Description

The Roland MV-8000 is a combination sequencer and sampler in a console-style housing with a built-in hard drive. The sequencer features 128 tracks, but initially only one channel could be recorded per track; pattern-based recording was only added with software version 3.5. The sampler is structured similarly to the older Roland S-700 series, allowing compatibility with its sample CD-ROMs. A patch can contain up to 128 partials, each with up to four samples that can be cross-faded. Samples can have one loop with forward, backward, or alternating playback options. All samples of a project need to be stored in the internal memory (expandable to 512MB). The hard drive is used solely for saving projects.

Features

  • 128-track sequencer
  • sampler compatible with Roland S-700 series CD-ROMs
  • up to 128 partials per patch
  • up to four samples per partial
  • sample looping
  • 512MB expandable memory
  • built-in hard drive for project saving
