Roland 140 System 100M, 2 Env/LFO Module

Synthesizer Addons Year: 1979

Description

The 140 module provides two envelope generators and LFOs for the System-100M. Combined with the 110 module, it provides the essential elements for producing synthesizer sounds. When used with modules 112, 121, and 130, enough elements are available to create two voices simultaneously. The LFO (voltage-controlled low-frequency oscillator) with built-in delay allows for delay/vibrato effects. The keyboard/trigger switch allows phase locking of the LFO output with the keyboard trigger pulse. The envelopes (ADSR) can be triggered manually via a rotary knob, via trigger gate, or via an internal/external gate.

Features

  • 2 Envelope Generators
  • 2 LFOs
  • Delay/Vibrato effects
  • Keyboard/trigger switch
  • ADSR envelopes
  • System-100M compatible
