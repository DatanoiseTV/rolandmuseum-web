Roland RS-505 String Paraphonic 505, Keyboard Synthesizer

Analog Synthesizer Year: 1978

Description

The RS-505, named 'Paraphonic 505' on its casing, is an analog 49-key keyboard with 3 sound generation sections and two keyboard zones, Upper and Lower, which have a fixed split point at middle C. The bass section consists of a monophonic synthesizer with 3 toggle-switchable sounds (Contra Bass 16, Tuba 8, and Cello 8) and an adjustable AR envelope. The 'Synthesizer' section has fixed registers but offers a filter with adjustable cutoff frequency and resonance, which can be modulated by an LFO or an ADSR envelope. It has a single envelope generator for all voices. The string section offers 8' and 4' string mix, and attack control. An LFO, vibrato, ensemble effect (I, II, or off), autobend function, and pitch lowering are also available. Rear panel includes stereo, synth-bass, trigger, and gate outputs, and external audio, pitch, sustain, and VCF control inputs.

Features

  • Analog 49-key keyboard
  • 3 sound generation sections (String, Synthesizer, Bass)
  • Two keyboard zones (Upper/Lower) with fixed split point
  • Monophonic bass section with 3 selectable sounds (Contra Bass 16, Tuba 8, Cello 8) and AR envelope
  • Homophonic synthesizer section with fixed registers and VCF with adjustable cutoff/resonance, LFO/ADSR modulation
  • Single envelope generator for all voices
  • Switchable ensemble effect (I, II, or off)
  • Homophonic string section with 8' and 4' string mix and attack control
  • LFO with adjustable rate and delay
  • Adjustable vibrato
  • Autobend function or manual pitch lowering up to an octave
  • Overall tuning and volume controls
  • Stereo output, Synth-Bass output, Trigger output, Gate output
  • External audio input (Ext IN), Pitch input, Sustain input, VCF control input
  • Includes DP-1 footswitch (sustain pedal) and PJ-1 audio cables
