182 System 100M, Analog Sequencer

Sequencer Year: 1979

Description

The Module 182 of the System-100M is a 2-channel, 8-step analog sequencer. The 2 channels can be operated in parallel or in series, providing a maximum of 16 steps. Continuous repetition or single pass-through is possible with the 'Repeat/Single' switch, and the number of steps can also be shortened to values smaller than 8 or 16. The speed can be controlled by a rotary knob or externally with a control voltage. Additionally, the steps can be advanced externally with a trigger signal. These diverse control options allow for the creation of very complex rhythmic patterns. The Module 182 is also Roland's last sequencer where steps can be individually adjusted directly via knobs. Simultaneously, the CSQ-100 was available, whose steps could be entered or played in via a CV/Gate keyboard. Furthermore, sequencers like the MC-8 or later MC-4 existed, whose steps could be programmed.

Features

  • 2-channel, 8-step analog sequencer
  • Channels can be operated in parallel or in series (up to 16 steps)
  • 'Repeat/Single' switch for continuous repetition or single pass
  • Adjustable number of steps (shorter than 8/16)
  • Speed control via rotary knob or external control voltage (CV)
  • External trigger signal input to advance steps
  • Individual step adjustment via dedicated knobs
  • Part of the Roland System-100M modular synthesizer system
  • Power supply via 190, 191 or 191J module cases
  • Dimensions: 104 x 230 x 199 mm
  • Weight: 1.6 kg
