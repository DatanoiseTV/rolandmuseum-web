Roland MC-4B Micro-Composer

Sequencer Year: 1981

Description

The MC-4 is a digital sequencer for CV/Gate signals with 4 independent tracks. Sequences can be programmed step-by-step or played in using a CV/Gate keyboard. Two-stage input (first pitches, then step length) is also possible. All entries can be edited on the MC-4, though one must get used to a special display on the 15-character screen. Per track, two control voltages (CV-1 and CV-2), Gate, and an "MPX" trigger signal for e.g., portamento, are available, allowing control over not only pitch but also dynamics or the filter of an connected synthesizer. The MC-4 has a built-in DIN-SYNC socket and can serve as a synchronization master or slave for other DIN-SYNC equipped devices. Via the TAPE SYNC connections, the MC-4 can also output an FSK signal, which can be recorded on a tape and later allow the MC-4 to run synchronously. Furthermore, the tempo can be controlled externally via a control voltage. Entered sequences must be saved to tape or cassette recorder before disconnecting power if they are to be used again. Accordingly, functions for saving, loading, and verifying data on external audio recording devices are available. The MC-4B features 48kB internal memory for approximately 11500 notes/events and an interface for the MTR-100 data cassette recorder.

Features

  • Digital CV/Gate sequencer
  • 4 independent tracks
  • Step-by-step programming
  • Real-time input via CV/Gate keyboard
  • Two-stage input (pitch then step length)
  • 15-character display for editing
  • Per track: CV-1, CV-2, Gate, MPX trigger signal
  • Built-in DIN-SYNC socket (master/slave functionality)
  • TAPE SYNC connections for FSK signal output
  • External tempo control via CV
  • Data saving/loading/verification to external audio recorders (tape/cassette)
  • 48kB internal memory (approx. 11500 notes/events) for MC-4B
  • Interface for MTR-100 data cassette recorder
  • Integrated power supply
  • Dimensions: 471 x 124 x 348 mm
  • Weight: 6.3 kg
